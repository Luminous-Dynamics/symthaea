# symthaea-structured-inconsistency

Production-neutral measurement crate for PARADOX-001.

The crate accepts explicit normalized measurements and returns deterministic reports that keep external surprise, internal disagreement, uncertainty, persistence, self-reference, evidence polarity, coherence, and a frozen candidate recruitment index separate.

It does not read or mutate the cognitive loop, workspace, Phi state, learning policy, precision, self-model, or action selection.

The `candidate_recruitment_index` is a preregistered descriptive stratification statistic for later experiments. It is **not** observed metacognition and is **not** a consciousness measure.

See `docs/research/PARADOX_000_STRUCTURED_INCONSISTENCY_PREREGISTRATION.md` and issues #3165 / #3166.
