# symthaea-algorithms

Typed, evidence-first contracts for describing computational problems, algorithm families, implementations, derivation lineage, evaluation, and multi-objective comparison.

This crate is intentionally non-authorizing. Registry presence, a benchmark receipt, or Pareto membership does not make an implementation executable or production-eligible.

See `docs/architecture/ALGORITHM_DISCOVERY_ARCHITECTURE_V1.md` and tracking issue #1318.
