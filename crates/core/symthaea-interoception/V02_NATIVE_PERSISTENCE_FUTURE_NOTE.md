# Future native persistence boundary

Status: **supporting / non-normative**

Initial v0.2 does not contain native affective persistence or native memory. Any later experiment claiming endogenous persistence should start a new architecture/evidence lineage, add an explicit qualified native persistent state or memory mechanism, and demonstrate targeted state-transfer, reset, and ablation evidence. External replay-history accumulators from v0.2 are not grandfathered into native mood or memory claims.
