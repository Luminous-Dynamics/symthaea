# Native Interoception v0.1

This crate provides deterministic, artificial viability-state primitives for
experiments on self-regulation. Its public API is intentionally independent of
semantic category labels, the cognitive loop, and the existing virtual-body
adapter.

## Research boundary

The crate models only:

- normalized viability variables,
- preferred and viable ranges,
- precision and importance,
- state velocity,
- deterministic prediction.

Higher-level interpretation is deliberately out of scope for this tranche.
