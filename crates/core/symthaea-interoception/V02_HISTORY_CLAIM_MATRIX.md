# Affective Emergence v0.2 — History Claim Matrix

Status: **supporting / non-normative**

This matrix summarizes the claim ceiling associated with the normative `history_access_basis` classes from `V02_HISTORY_STATE_SUFFICIENCY.md`.

| Basis | Allowed initial-v0.2 interpretation | Forbidden interpretation |
| --- | --- | --- |
| H0 current native state only | current-state-derived regulatory observable | native mood / memory unless a separate persistent mechanism exists |
| H1 replayed prefix history | external history-derived / path-dependent observable | native memory, remembered distress/reward, endogenous mood |
| H2 native persisted memory | reserved for a future separately qualified lineage | unavailable in initial v0.2 |
| H3 retrospective history | retrospective diagnostic | online/endogenous signal |
| H4 oracle future | oracle diagnostic | anticipation or affect available to the agent |

A later native persistence lineage should require explicit state identity, update/reset semantics, transfer/restart behavior, targeted ablation, and evidence that persistence is carried by the native mechanism rather than by the external observatory.
