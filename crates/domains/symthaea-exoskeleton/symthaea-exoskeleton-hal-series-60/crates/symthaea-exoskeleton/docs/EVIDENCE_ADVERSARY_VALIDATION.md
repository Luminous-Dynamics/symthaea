# Evidence Adversary Validation

A release verifier must reject nearby invalid capsules, not merely accept a valid fixture. Series 57 derives deterministic mutations covering release and provenance substitution, stale evidence, mixed bindings, duplicate artifacts, missing required evidence, privacy downgrades, duplicate reviewers, and reviewer self-approval.

Passing this campaign is necessary but not sufficient. Audited cryptographic test vectors, parser fuzzing, external penetration testing, and independent review remain required.
