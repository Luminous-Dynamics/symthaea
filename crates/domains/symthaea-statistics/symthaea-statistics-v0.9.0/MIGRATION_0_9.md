# Migration guide — v0.8 to v0.9

v0.9 is additive. Existing v0.8 APIs remain available.

## New latent-state APIs

Use `MarkovChain::try_new` for validated row-stochastic transition matrices. Use `HiddenMarkovModel::try_new` when states are latent and observations are categorical. Filtering, smoothing, and Viterbi decoding deliberately return separate result types so callers cannot confuse online and retrospective state probabilities.

## Multiclass outcomes

Use `try_multinomial_logistic_regression` when one outcome has more than two unordered classes. The final declared class is the reference class. Coefficient rows therefore have length `classes - 1`; prediction methods always return all class probabilities in original class-index order.

## Excess-zero counts

Use `try_fit_zero_inflated_poisson` when observed zeroes may arise from a structural-zero mixture. Use `try_fit_hurdle_poisson` when zero and positive outcomes are generated by explicitly separate processes. These v0.9 fits are intercept-only; retain the existing Poisson and negative-binomial regressions for covariate-dependent means.

## Paired and repeated outcomes

Use `try_sign_test` for exact direction-only paired evidence, `try_wilcoxon_signed_rank` when symmetric ranked differences are defensible, and `try_friedman_test` for complete repeated-measures blocks.

## Propagating uncertainty

Use `try_delta_method` for smooth local transformations and `try_monte_carlo_propagation` when nonlinear transformations make first-order approximations inadequate. Monte Carlo calls require explicit seeds and retain the generated output sample.

## Multiple imputation and nonparametric posterior uncertainty

Use `try_pool_imputation_estimates` or `try_pool_imputation_vectors` to combine estimates from completed datasets. Use `try_bayesian_bootstrap` when posterior uncertainty over empirical observation weights is the intended model; it is not a replacement for a missing-data model.

## Mixtures

Use `try_gaussian_mixture_1d` for deterministic univariate mixture exploration. Inspect component weights, means, variances, and responsibilities; compare scientifically plausible component counts rather than treating one EM fit as uniquely identified truth.
