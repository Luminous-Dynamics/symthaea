# Muse — music with provenance

The showcase site for [Symthaea Muse](https://github.com/Luminous-Dynamics/symthaea)
(`crates/domains/symthaea-muse`), served at **muse.luminousdynamics.io** via GitHub Pages.

This repo is presentation only — one static page plus OGG-encoded listening
demos, all composed by Muse. Content is synced from the symthaea monorepo by
`scripts/sync-site-to-standalone.sh`; edits here will be overwritten by the
next sync.

Every piece: symbolic composition, CC0 instrument samples, zero scraped
training data.
