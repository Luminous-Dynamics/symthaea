# Southern African Urban, Folk and Dance Traditions — Research Brief v1

**Status:** Eight catalog identities, all Research; expert review required. None has a composer route. This improves discoverability and identifies research work; it does not imply implementation or authenticity.

The new constellation is an indexing boundary, not a claim that these styles share one engine. Each needs a separate definition, source trail, intended mechanism and specialist review.

## Minimum gate before a composer route

1. Maintain a source bibliography and state what it supports and leaves uncertain.
2. Define a versioned grammar contract with target/non-target behavior and a falsifiable observable.
3. Implement a style-specific mechanism behind the routed composition path; never use a generic route to inflate coverage.
4. Run deterministic response curves, seed robustness, and nearest-route comparisons.
5. Record renderer availability and instrument/sample substitutions separately.
6. Require knowledgeable-musician/researcher review before authenticity claims or Foundation promotion.
