# Changelog

## 0.4.0

- Add provenance-bearing observed, stipulated, and assumed fact assertions.
- Add bounded grounded recursive inference for typed rule packs.
- Add explicit ambiguity-blocking and ambiguity-propagating semantic profiles.
- Retract conclusions when later-derived exceptions become active and reject
  oscillating theories explicitly.
- Add local typed query explanations and transitive canonical proof graphs.
- Preserve checked-absent rule exceptions as proof guards and canonical evidence.
- Add temporal rule-pack selection and static revision-overlap auditing.
- Add transactional evaluation sessions with deterministic result deltas.
- Add explicit within-day lifecycle event ordering without treating event IDs
  as hidden timestamps.
- Add canonical evidence encodings for recursive results, explanations, proof
  graphs, temporal results, fact bases, and evaluation deltas.
- Add recursive-profile validation findings and conservative dependency impact
  indexing.

## 0.3.0

- Add validated typed strict, defeasible, and defeater rules.
- Add versioned rule packs with explicit acyclic superiority graphs.
- Add skeptical direct conflict resolution with four-valued outcomes and
  auditable defeat records.
- Separate legal effectiveness from applicability and reject ambiguous temporal
  revision overlap.
- Add norm lifecycle assessment for activation, fulfillment, exercise,
  violation, waiver, expiry, deadlines, and reparative norms.
- Add Hohfeldian legal-position states and transactional power exercises.
- Add schema-tagged canonical evidence envelopes for external hashing and
  signing.
- Add deterministic rule-pack lint reports and cross-module conformance tests.
- Forbid unsafe Rust while retaining a zero-dependency runtime kernel.

  stratification.

- Add canonical derivation traces and direct `why_not` diagnostics.
- Distinguish permitted, forbidden, conflicted, and undetermined acts.
- Add party-bound structured norms.
- Add validated legal identifiers and explicit positive/negative literals.
- Add instantiated Hohfeldian relations and contradiction detection.
- Add source, jurisdiction, authority, and inclusive effective-date context.
