# Phase A.3 Evaluation Freeze Manifest

Written and committed **before** running the frozen USPTO template-coverage evaluation
(`examples/uspto_evaluation.rs`), per the review that recommended it: record everything needed to
reproduce or audit the run, then prohibit chemistry changes to this crate until the first full
result is recorded. This file is the record.

## Source dataset

- **Dataset**: USPTO-50K (retrosynthesis framing), via `PyTDC`'s `tdc.generation.RetroSyn`.
- **Access**: `pip install PyTDC==1.1.15` (see "Tooling versions" below), then:
  ```python
  from tdc.generation import RetroSyn
  df = RetroSyn(name='USPTO-50K').get_data()
  ```
- **Shape**: 50,037 rows, 2 columns (`input` = product SMILES, `output` = dot-separated reactant
  SMILES — TDC's retrosynthesis framing is reversed from a normal reactants→product record).
- **License**: CC0 (public domain).
- **Raw CSV sha256**: `ab4be5b428d54ef8296bfb46a2d09f89306fad860afb3f8a81b81ec75eaf33d4`
  (of the CSV as written by `df.to_csv('uspto50k.csv', index=False)` immediately after fetch,
  2026-07-13). **Not committed to this repo** (5.2MB, trivially re-fetchable and independently
  verifiable against this hash via the exact call above) — the derived candidate TSVs below,
  which ARE the actual frozen inputs to the evaluation, are committed.

## Extraction: SMARTS prefilter → candidate sets

- **Script**: `external_corpus/filter_probe.py` (committed, unmodified from the run that produced
  the candidate files below).
  - sha256: `b37461f4a0b301e548baf83ce754a525379abad8aa64f4bf9ee539b9ce6f1511`
- **Esterification-shaped filter**: reactant set (2 molecules) contains one carboxylic acid
  match (`[CX3](=O)[OX2H1]`) and one non-acid alcohol/phenol match (`[#6][OX2H1]`); product
  matches an ester linkage (`[CX3](=O)[OX2H0][#6]`).
- **Hydrogenation-shaped filter**: reactant set is exactly 1 molecule; count of
  `[#6]=[#6]`/`[#6]#[#6]` SMARTS matches is strictly higher in the reactant than in the product.
- **Result**: 50,037 records scanned, 0 SMILES parse failures, **558 esterification-shaped**,
  **724 hydrogenation-shaped** candidates.
- **Candidate TSV hashes** (pre-split, generated by `filter_probe.py`):
  - `ester_candidates.tsv`: `fd4b35a4dc787276925eb5219a611519fb593d7119a5b202a8d614ae16e819d9`
  - `hydro_candidates.tsv`: `e2551298ca3bccdbb7e3363bbdaabbbc8bf884c85b9f51407b192ec1a6c9fcd0`

**Explicit, important caveat**: this filter checks structural *shape* only (does the reaction
resemble an esterification or hydrogenation), not whether this crate's actual
`EsterificationTemplate`/`HydrogenationTemplate` would compute the exact declared product. That
determination is what `examples/uspto_evaluation.rs` exists to make.

## Scaffold-grouped dev/validation/holdout split

- **Script**: `external_corpus/scaffold_split.py` (committed).
  - sha256: `4c5132584f3677d94474e7927c5dc36b4be1006ec077ab3dd7c9de719a024075`
- **Method**: each candidate's product is reduced to its Bemis-Murcko scaffold (RDKit
  `MurckoScaffold.GetScaffoldForMol`; acyclic products fall back to their own canonical SMILES as
  the grouping key). Every candidate sharing a scaffold is assigned to the SAME split via a
  deterministic hash of the scaffold string (not a random per-row draw) — this is what prevents
  near-duplicate/related patent reactions from leaking across dev/validation/holdout.
- **Split committed as**: `external_corpus/uspto50k_scaffold_split/{ester,hydro}_candidates_split.tsv`
  - `ester_candidates_split.tsv` — 558 rows, 380 distinct scaffolds, split counts: dev=223,
    validation=221, holdout=114
  - `hydro_candidates_split.tsv` — 724 rows, 538 distinct scaffolds, split counts: dev=318,
    validation=235, holdout=171

**How the split is used in THIS pass**: per the review's own framing, the split protects *future*
template-improvement work (a dev set to iterate against, validation/holdout kept untouched until
a later frozen re-evaluation) — it does not change how this first pass is scored, since no
chemistry changes are made based on this run's results. The first full evaluation runs and
reports on **all 1,282 candidates**, with results also broken out per split so the split is
immediately usable for any future round.

## Crate state (frozen, not modified for this evaluation)

- **Git commit at freeze time**: `cef0a2a830` (`docs(symthaea-process-discovery): correct Phase
  A.3 scoping estimate with real probe data`) — the last commit touching this crate before the
  evaluation harness was added. `examples/uspto_evaluation.rs` calls only the crate's existing
  public API (`oracle::evaluate`, `templates::{EsterificationTemplate,HydrogenationTemplate}`,
  `isomorphism::is_isomorphic`, `normalization`, `validity`, `policy`, `pubchem`, `rdkit`,
  `formula`) — **no changes to any of those modules for this evaluation.**
- **Templates**: `EsterificationTemplate` (R-COOH + R'-OH → R-COO-R' + H2O),
  `HydrogenationTemplate` (C-C multiple bond + H2 → saturated, C-C restricted only) — unchanged
  since Phase 1.1.
- **Normalization**: one rule (`normalization.rs`) — neutral nitro → charge-separated. Unchanged
  since Phase A.1.
- **Policy**: `OpenWithHeuristicScreenPolicy` (same policy `audit.rs`'s corpus auditor uses) —
  hazard-heuristic screen (nitro/peroxide/unsaturation-ratio), no reactant-library restriction.
- **Graph-equivalence procedure**: `isomorphism::is_isomorphic(a, b)` — bounded exact
  labeled-graph isomorphism (`MAX_ATOMS_FOR_EXACT_CHECK=40`, `MAX_BACKTRACK_STEPS=2,000,000`,
  fails closed to "not isomorphic" on any bound exhaustion). Used in place of formula-string
  equality for determining whether a computed product matches a declared product — formula
  equality alone cannot distinguish constitutional isomers (a real gap the review flagged).

## Tooling versions (extraction/evaluation-support only, not a crate dependency)

  and is not tied to this specific version).
- `pandas` (version pulled transitively by PyTDC at install time, not independently pinned here).

## Resource limits / timeout behavior carried into the evaluation

- PubChem cross-reference: 10s timeout, 64KiB response cap, 250ms throttle between real network
  calls (`pubchem.rs`, unchanged from Phase A.1/A.2).
- RDKit cross-reference: 10s subprocess timeout, 8KiB output cap (`rdkit.rs`, unchanged from
  Phase A.2).
- Isomorphism check: bounded as described above; every bound-exhaustion event is counted via
  `isomorphism::diagnostics()` deltas, reported as a distinct outcome category
  ("resource-bounded uncertainty"), never silently treated as either a match or non-match.
