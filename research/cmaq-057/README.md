# CMAQ-057 — Predictable adaptive kernel betting

## Paradigm

CMAQ-054 uses a frozen mixture over kernel experts. CMAQ-055 adds a frozen mixture over possible change starts. These are valid and useful, but the priors impose representation/onset complexity costs.

For direct conditional paired equality, a more adaptive construction is available. At each time t, choose one representation and one betting direction using only past observations and the current covariate Z_t (if it is available before the pair). Then form a bounded paired feature difference and place one predictable bet. The selected map may change every observation.

This is not post-hoc expert selection. It is one prequential betting process.

**Novelty boundary:** SCPT already adapts KNN neighbourhoods using past covariates and updates covariate-dependent betting fractions from historical discrepancy statistics. CMAQ-057 is not claiming predictable betting or adaptive lambda as new. Its narrower hypothesis is that a lagged policy over finite Fourier response/covariate representations and historical feature directions can improve high-dimensional / multiscale conditional detection while keeping one valid betting process. SCPT itself identifies high-dimensional covariate handling as a limitation and suggests learned representations and data-adaptive distance metrics as future directions.

## Conditional null and theorem

Let F_(t-1) contain all past pairs and policy state. The current covariate Z_t is available before X_t and Y_t. Assume:

    Law(X_t | Z_t,F_(t-1)) = Law(Y_t | Z_t,F_(t-1)).

Before observing the current pair, the policy selects:
- response map phi_t;
- covariate map psi_t;
- unit-ball direction u_t;
- betting rate lambda_t in (0,1).

Every choice is measurable with respect to the pre-pair information generated by F_(t-1) and Z_t. For unit-normalized Fourier maps define:

    r_t = 0.5 * psi_t(Z_t) tensor [phi_t(Y_t) - phi_t(X_t)].

Then ||r_t||_2 <= 1 and E[r_t | F_(t-1), Z_t] = 0.

For the singleton target S={0}, the support value is zero. Define:

    q_t = <u_t,r_t>
    f_t = 1 + lambda_t*q_t
    M_t = product_(i<=t) f_i.

Because ||u_t||_2<=1, |q_t|<=1. With lambda_t in (0,1), f_t is strictly positive. Conditional paired equality gives:

    E[f_t | F_(t-1),Z_t] = 1.

Thus M_t is a nonnegative martingale (and in particular a supermartingale) under the direct null. Ville's threshold 1/alpha gives one anytime-valid test.

No Bonferroni or fixed kernel-prior alpha split is used because exactly one bet is made at each time. This is not a claim that kernel adaptation is free: the policy may pay through exploration delay, instability or regret relative to the best fixed expert. Sreedhar & Li's ICML 2026 kernel-family work proves an additive log(K) sample-complexity cost for competing with the post-hoc best kernel, with a matching lower bound. CMAQ-057 must be evaluated against that limit; it does not evade it by using one predictable strategy.

### What the theorem does not allow

- Selecting the feature map after seeing the current X_t or Y_t.
- Selecting lambda_t or u_t from the current residual.
- Computing many same-time expert e-values and reporting their maximum at the original alpha.
- Altering the null, target, norm bound or calibration mode after seeing evidence.

A deterministic policy selected from past discrepancies is allowed. Under the null, conditioning on its complete past state still leaves the next paired feature difference centered.

## Stage 1 implementation

The Rust crate builds a deterministic lagged-scale policy over a fixed inventory of Fourier maps. At time t:
1. It selects the expert with the largest historical cumulative feature-difference norm, using no current-pair information.
2. It sets u_t to that expert's normalized historical feature sum (or zero before any evidence).
3. It applies one bounded bet with a frozen lambda in (0,1) to the selected expert's current pair feature.
4. It also emits one separately valid prequential factor for every registered expert, using that expert's own historical direction. These factor streams allow CMAQ-058 to form the exact kernel × start mixture with O(K) restart bookkeeping.
5. Only after the e-process increments are computed does it stage the current pair's feature differences into all policy summaries for use at t+1.
6. It commits wealth, policy summaries, sequence and pair ID atomically.

The manifest and typed risk plan must be in DirectConditionalPairedEquality mode. The feature inventory is recomputed against the CMAQ-056 content-addressed plan at construction.

The default constructor enforces its own 1/alpha_test threshold. The separate `new_unthresholded` constructor is for a parent such as CMAQ-058: it continues emitting the same valid predictable factors after the child wealth crosses 1/alpha_test, marks `threshold_enforced=false` in each action receipt, and leaves the sole quarantine decision to the outer process. Its policy digest is distinct from the threshold-enforcing mode. Do not use this mode without a parent that owns the risk decision.

For atomic parent composition without replay-ledger cloning, the monitor exposes `prepare_pair` and `commit_prepared`. Preparation computes the next update and candidate policy state without mutation; a parent may validate its aggregate wealth first, then commit the prepared child state. The prepared object is bound to the base sequence and policy-trace digest, so stale commits fail closed. The ordinary `observe_pair` remains the prepare-plus-commit convenience API.

This first policy keeps feature dimension and number of candidate maps fixed. It adapts the selected representation and direction; it does not generate an unbounded new feature dimension.

## Complexity and expected trade-off

With K candidate maps and D product features per map, the direct implementation computes all candidate paired features each step, giving O(KD) work and O(KD) policy state. The betting state is O(D) and replay identity is stored once.

Unlike the fixed prior mixture, this process spends only one bet per observation and requires no per-kernel alpha split. But it does not carry a theorem that it competes with the best expert at no complexity cost. Its lagged selection rule can be slower than the mixture, especially when early evidence is weak, and may incur its own exploration/regret penalty. It can also miss alternatives orthogonal to every candidate map or poorly aligned with the policy's lagged selection score.

## Tests and probe

The crate tests:
- equal-pair null paths preserve unit wealth;
- the selected expert at t is determined by history before pair t;
- feature summaries are updated only after the bet;
- the chained policy trace changes with pair-feature history and is returned with every update;
- invalid input/replay/sequence failures do not mutate policy or e-process state;
- reference-calibrated typed plans are rejected;
- changed runtime feature maps fail the CMAQ-056 manifest check;
- non-finite values and invalid betting rates fail closed.

The probe compares a fixed two-expert CMAQ-054 mixture with this single prequential adaptive bet on an equal-marginal conditional-pairing fixture. It is a wiring/power-direction smoke check, not empirical Type-I qualification.

## Research comparison

SCPT is the primary conditional paired-sample comparator. Its Algorithm 1 already chooses KNN neighbourhoods from past covariates and computes its next betting fraction from historical neighbourhood statistics. It must be reproduced faithfully as an adaptive comparator, not reduced to a static-kernel straw baseline. Its discussion also identifies high-dimensional covariates and nearest-neighbour curse-of-dimensionality as an open limitation, motivating learned representations and adaptive distance metrics. CMAQ-057's hypothesis is specifically about a different adaptive object: the bounded Fourier feature map and its lagged evidence direction.

The ICML 2026 kernel-family mixture is the required representation-adaptation comparator. Its authors report an additive log(K) sample-complexity cost to compete with the post-hoc best fixed kernel and a matching lower bound. CMAQ-057 should therefore report detection delay and regret relative to the best fixed expert, not claim to eliminate the family-selection price.

CMAQ-054 and CMAQ-055 are internal fixed-mixture ablations. PF-CCTM and Online RFF-MMD belong in separate related-protocol tables, not the same primary task.

Primary qualification requires at least 10,000 independent full-horizon null paths and 5,000 alternatives per registered cell, alpha in {0.01,0.05,0.10}, misses counted as H+1, and confidence intervals on ever-alarm and unconditional detection. Paired inference uses independent common-cause blocks.
