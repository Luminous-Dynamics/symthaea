# D4 finite-reference regression symmetry corpus v0.1

Executable fixture generator for issue #12850, composed with the exact D4 matrix-action and polynomial oracle in benchmark PR #12849.

## What this increment establishes

A reproducible finite-dimensional regression corpus with exact known invariance subgroups, generated by the Reynolds operator—not by assigning labels to arbitrary polynomials.

For each of the ten distinct D4 subgroups:
1. Generate a deterministic bounded integer-coefficient base polynomial in the 15-dimensional two-variable polynomial basis of total degree at most four.
2. Apply the exact finite-group Reynolds projection P_H f(x) = |H|^-1 sum_{h in H} f(h^-1 x).
3. Compute the resulting exact stabilizer using the independent symmetry-discovery-benchmark-oracle crate.
4. Reject the candidate unless its complete stabilizer is exactly H.
5. Retain the deterministic seed/attempt and a separate exact ground-truth record.

The generator constructs 90 accepted functions per subgroup, with 30 in each discovery, calibration and final-holdout cohort: 900 function instances total.

## Sampling contract

Each function receives separate deterministic training, calibration and holdout sample substreams. Point coordinates are sampled from the product-uniform discrete grid {-2.0,-1.9,...,2.0}², represented as integer tenths. Samples are disjoint across all three substreams within a function.

The feature vector is the frozen 15-dimensional monomial basis (total degree <=4). Training designs are required to have full column rank modulo the prime 1,000,000,007; a nonzero determinant modulo this prime is an exact certificate of full column rank over the rationals.

Targets are exact signed-integer rationals. Public data uses one common denominator across all ten target subgroup sizes, so the target's scale does not directly disclose the subgroup order.

Sample counts per function: 32 training, 16 calibration, 32 holdout.

Run:

    cargo test --locked --manifest-path research/symmetry-colt-regression-001/Cargo.toml
    cargo clippy --locked --manifest-path research/symmetry-colt-regression-001/Cargo.toml --all-targets -- -D warnings
    cargo run --release --locked --manifest-path research/symmetry-colt-regression-001/Cargo.toml -- --output-dir ./d4-regression-corpus

This writes public_inputs/discovery.json, public_inputs/calibration.json, public_inputs/final_holdout.json, and generation_receipt.json.

Add --include-ground-truth to write ground_truth.json separately. Public split files contain no target subgroup label, subgroup element list, polynomial coefficient vector or generation seed. The ground-truth file contains exact coefficient numerators/denominators, subgroup labels, generator provenance and oracle scope.

**This repository is public, so this is a reproducible public corpus, not a sealed evaluation leaderboard.** A sealed holdout requires a separately controlled evaluator and must not be implied by the open files.

## The COLT 2026 comparison boundary

Soleymani, Tahmasebi, Jaillet & Jegelka (COLT 2026) prove polynomial-time symmetry recovery and minimax-optimal sample complexity for their stated regression/finite-group setting. The abstract alone is not enough to reconstruct all assumptions, estimator steps, sampling rules or constants. Therefore this increment supplies the exact D4 synthetic data and oracle foundation only.

It does **not** claim a faithful reproduction of their algorithm, theorem assumptions, sample-complexity guarantee, or any SOTA advantage. Those need a separate paper-to-code specification and matched baseline implementation. The next stage must extract the formal model from the full paper, map every assumption to the generator, then implement the published estimator faithfully.

Reference: https://proceedings.mlr.press/v336/soleymani26a.html

## Claim boundary

Exact D4 finite-group invariance labels on synthetic regression functions and deterministic rational samples only. No COLT theorem reproduction, noisy-regression guarantee, unknown ambient group, continuous group, physical dynamical system, or permission to prune a search space is established.
