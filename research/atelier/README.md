# Atelier multi-family product system v0.1

This directory contains the collection-level product/route architecture and a machine-readable planning catalog.

- `multifamily-product-system-v0.1.md` — full design-to-manufacture roadmap.
- `style-family-catalog.v0.1.json` — 13 style-family records, their candidate construction routes, functional profiles and critical engineering concerns.

The catalog is a planning taxonomy only. It is not a production capability list, a pattern standard, a claim that any process is qualified or a commitment to manufacture all listed families.

Use the existing product, pattern, process, equipment, simulation and lifecycle owners. The catalog is a collection-level index, not a new source of truth for their domain data.
