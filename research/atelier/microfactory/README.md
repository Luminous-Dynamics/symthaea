# Atelier microfactory reference architecture

This directory contains the synthetic-first reference design for ATELIER-MICROFACTORY-001 #12288.

- ../microfactory-reference-v0.1.md — factory architecture, flow, utilities, workcells, SOTA comparison and benchmark.
- ../factory-layout-catalog.v0.1.json — machine-readable zones, flows, layout alternatives, utility profiles, disruption scenarios and hard constraints.

The reference is not a site/building/permit/engineering design. Gross-area scenarios of 120/200/300 m² are synthetic comparison envelopes only. No factory capacity, capex, site suitability, safety or environmental claim is made.

Compose the existing factory/site/building/scheduling/commissioning owners rather than introducing parallel infrastructure.
