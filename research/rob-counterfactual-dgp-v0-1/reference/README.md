# Runnable reference

This folder contains the pure-Python research reference for MCR² v17.

Run from this directory:
~~~bash
python3 run_benchmark.py
python3 -m unittest discover -v
~~~

The generator uses only the Python standard library. JSON Schema sample validation may be run with a Draft 2020-12 validator such as python-jsonschema. It is not a production controller, survival estimator, causal estimator, simulator or hardware adapter.
