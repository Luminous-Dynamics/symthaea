# MON-007 Node RFC 9162 verifier

This is an independent JavaScript implementation of RFC 9162 SHA-256 leaf/node hashing, inclusion verification, consistency verification, and fixture proof generation. It uses Node's built-in `node:crypto`; no npm dependencies are required.

## Reproduce from the repository root

```sh
mkdir -p /tmp/sfeb-mon007-js/testdata
for f in rfc9162.mjs rfc9162.test.mjs generate-rfc9162-vectors.mjs; do
  gzip -dc "benchmarks/frontend/monitoring/sfeb-mon007/js/${f}.gz" > "/tmp/sfeb-mon007-js/${f}"
done
cp benchmarks/frontend/monitoring/sfeb-mon007/js/testdata/rfc9162-go-generated-v1.json.gz /tmp/sfeb-mon007-js/testdata/
cp benchmarks/frontend/monitoring/sfeb-mon007/js/testdata/rfc9162-node-generated-v1.json.gz /tmp/sfeb-mon007-js/testdata/
node --check /tmp/sfeb-mon007-js/rfc9162.mjs
node --check /tmp/sfeb-mon007-js/generate-rfc9162-vectors.mjs
node --test /tmp/sfeb-mon007-js/rfc9162.test.mjs
node /tmp/sfeb-mon007-js/generate-rfc9162-vectors.mjs 16 /tmp/rfc9162-node-generated-v1.json
```

The two gzip fixture corpora each contain 136 inclusion and 120 consistency vectors. One corpus is generated by Go; the other is generated independently by Node.

## Differential evidence

Node independently verifies every Go-generated proof. The Node fixture builder independently generates the same roots and paths; the Go test suite verifies that corpus. The two test suites also exercise altered hashes, malformed paths, truncation, excess nodes, invalid sizes, and exact-power-of-two boundaries.

The Go implementation additionally exhaustively tests 65,536 generated proof cases through tree size 256. Five fresh Node test-runner invocations passed all seven RFC 9162 tests each.

This is bidirectional implementation differential testing, not standards certification. The verifier consumes already-decoded digests and supplied roots. It does not parse COSE/CBOR, authenticate signed checkpoints, verify SCITT receipts, or implement witness gossip/split-view detection.
