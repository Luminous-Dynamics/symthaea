# MON-014 digest-context preflight

Standard-library Go semantic checker for declared cross-profile digest comparability, Agent Action Capsule -06 effect-attestation grades, and destination-plus-observer effect qualification. It consumes normalized verifier results; it does not implement signatures, COSE, OAR or SCITT.

Run:

    go test -race -count=5 ./...
    go vet ./...
    go test -count=1 -cover ./...

A matching hex digest across distinct contexts is incomparable, not equal.
