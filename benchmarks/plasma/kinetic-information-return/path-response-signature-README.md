# KIRR path-conditioned response signature fixture v0.1

This fixture tests how a complex KRS response signature is bound to a KIRR pulse sequence and assigned an empirical disposition.

Every signature has one intervention axis. At runtime that identity is populated from the actual `KineticPulseSequence::digest()`; this avoids hard-coding a digest generated by another implementation. The signature also carries the declared structure class, ordered QoIs, fixed per-QoI scales, strictly increasing observation times, complex response entries and branch IDs.

Five synthetic known-answer cases exercise:
- PASS: complete response and branch coverage within tolerance;
- FAIL: confirmed branch mismatch;
- FAIL: measured normalized response error above tolerance;
- UNKNOWN: missing response and unresolved branch;
- UNSUPPORTED: incompatible structure classes.

The Rust unit suite builds the sequence from the checked-in pulse graph, constructs the candidate/reference signatures from this fixture, binds them to the runtime sequence digest and verifies the disposition / diagnostic counts. The schema validates wire shape; semantic checks in Rust validate the path identity and observation window.

No Vlasov solver or echo was run. These are synthetic disposition tests, not physical response measurements or global guarantees.
