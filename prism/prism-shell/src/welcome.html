Prism

A consciousness-aware pure Rust browser with epistemic search.

No JavaScript engine. No C++ dependencies. Zero attack surface from JIT compilers. Every page is rendered through the immune system before you see it.

Try It

Type a URL in the address bar and press Enter to navigate. Or type a search query to search the knowledge base. Click links to follow them.

  • Try searching: ocean acidification
  • Try searching: consciousness
  • Try searching: rust programming
  • Try navigating: https://example.com

Keyboard Shortcuts

  • F6 — Focus address bar
  • Enter — Navigate or search
  • Escape — Cancel, return to current page
  • Space — Scroll down
  • Mouse wheel — Scroll

Security

Every page passes through a two-stage immune system:

  • Stage 1: URL and header classification (sub-microsecond)
  • Stage 2: Aho-Corasick DOM text scan (sub-millisecond)
  • Privacy gate: Three-zone model (Private / Local / Public)
