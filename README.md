## Architecture

The portal is built with [Leptos](https://leptos.dev) — pure Rust CSR (Client-Side Rendering). The UI, the state management, and the consciousness engine are all Rust compiled to WASM.

```
Leptos UI (552KB WASM)  ←→  Web Worker  ←→  SporeEngine (400KB WASM)
     ↑                                            ↑
  Pure Rust                                   Pure Rust
  Reactive signals                            HDC + CfC + IIT + FEP
```
