# symthaea-cosmogenesis

A research-grade algorithmic instrument for studying semantic manifold organization using ΛCDM-inspired cosmological dynamics.

## Purpose
This crate models "Cognitive Cosmogenesis"—the hypothesis that meaning forms like structure in an expanding, gravitationally-tethered universe. We treat semantic vectors (HDC-like) as particles in a high-dimensional manifold, subject to forces of attraction (semantic similarity), expansion (novelty pressure), and latent mass (memory priors).

## Core Components
- **CosmogenesisSimulator:** An iterative physics engine that evolves a semantic manifold based on tuned cosmological parameters (`lambda`, `attraction_strength`, `cooling_rate`).
- **CosmicWebAnalyzer:** Extracts topological 'circuitry' from the manifold, identifying key concept hubs and pathways.
- **PhaseTransitionDetector:** Detects 'critical points' of structural formation by monitoring the acceleration of cluster separation.
