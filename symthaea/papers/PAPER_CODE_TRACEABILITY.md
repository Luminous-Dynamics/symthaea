## Key Files

### Core FEP Implementation
- **`src/consciousness/fep_active_inference.rs`** — Main HAI implementation: `EnhancedFEPBridge`, `MotorCommandType`, precision dynamics, EFE computation
- **`symthaea-core/src/hdc/predictive_coding.rs`** — Lower-level `PredictiveCoding` and `ActiveInference` structs operating on BinaryHV
- **`src/consciousness/predictive_processing.rs`** — Precision-weighted prediction errors with `ErrorDirection` enum
- **`src/consciousness/hierarchical_free_energy.rs`** — Hierarchical free energy decomposition

### HDC Primitives (§2.2)
- **`symthaea-core/src/hdc/unified_hv.rs`** — `ContinuousHV`, `BinaryHV`: bind, bundle, similarity
- **`symthaea-core/src/hdc/mod.rs`** — `HDC_DIMENSION = 16_384`

### Benchmarks (§4)
- **`src/benchmarks/fep_temporal_benchmark.rs`** — T-Maze and Grid World benchmarks
- **`symthaea-core/src/core/gridworld.rs`** — Grid World environment
- **`examples/fep_active_inference_demo.rs`** — Interactive demo

### Motor Commands (§3.4, Table 1)
All 8 types defined at `src/consciousness/fep_active_inference.rs:2278`:
```
0: AttentionShift       — High precision error in modality
1: LearningRateAdjust   — Rapid confidence change
2: ExplorationTrigger   — Epistemic > pragmatic EFE
3: ReflectionInitiate   — High F, stable beliefs
4: MemoryConsolidate    — Persistent low prediction error
5: ExpectationReset     — Persistent high error
6: MotorOutput          — External action required
7: NoOp                 — System at equilibrium
```

## Reproducing Paper Results

```bash
# Unified reproduction script (all paper-cited benchmarks in one run)
cargo run --example reproduce_all_benchmarks

# Ablation baselines (HDC-only vs CfC-only vs Full vs HDC-LTC)
cargo run --example ablation_baselines

# Run FEP active inference tests
cargo test test_fep_active_inference --release

# T-Maze with reward loop (v0.6+)
cargo test --lib -- t_maze --release

# Run Grid World
cargo test gridworld --release -p symthaea-core

# Full integrated pipeline
cargo test test_integrated_pipelines --release
```
