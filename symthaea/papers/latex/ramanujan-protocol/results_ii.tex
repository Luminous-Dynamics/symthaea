\section{Results II: Autonomous Conservation-Law Discovery}
\label{sec:results2}

Where Section~\ref{sec:results1} demonstrated the closed-loop pipeline on
sequence-discovery targets, this section reports the engine's autonomous
discovery of conservation laws directly from integrated trajectories of
canonical dynamical systems. Each entry in Table~\ref{tab:autonomous} was
obtained with \textit{zero human guidance}: the input is the ODE right-hand
side and an initial condition, and the output is a symbolically-proven
first integral (or, in the case of chaotic non-integrable systems, an
explicit null result).

\subsection{Experimental Protocol}

For each system, the engine performs the following without intervention:
\begin{enumerate}
  \item Integrate the ODE with adaptive Verlet/RK45 to produce a reference
        trajectory of length $T$.
  \item Run Phase~0 --- seed the GP population with templates from
        \texttt{build\_invariant\_templates}, weighted by dimensionality
        and the detected topology of the state space.
  \item Run Phase~1 --- 3-seed ensemble symbolic regression, minimizing
        scale-invariant trajectory variance (squared coefficient of
        variation on the candidate invariant along the integrated path).
  \item Filter candidates through the non-triviality gate (reject constants,
        reject near-zero artifacts from transcendental identities like
        $\sin(\pi)^{\pi x}$).
  \item Verify surviving candidates against the ODE right-hand side via
        the chain-rule calculus bridge: a candidate $I(\mathbf{x})$ is
        \textbf{PROVEN} iff $\nabla I \cdot \mathbf{f} \equiv 0$ symbolically.
  \item Route the proven invariant through the 216-equation physics catalog
        using the structural + dimensional + symmetric similarity metric
        introduced in Section~\ref{sec:architecture}.
\end{enumerate}

The full showcase including all six dynamical systems completes end-to-end
in approximately $45$ seconds of wall-clock time on a commodity CPU (no
GPU, no external solvers beyond Z3 for the Results~I triangular induction).

\subsection{Aggregate Performance}

Across the seven showcase targets, \textbf{six receive proven status}
(five chain-rule proven, one Z3 induction proven) and route to their
correct catalog cousin at $\geq 0.998$ similarity. The single failure
case (PCR3BP) is flagged honestly as \texttt{Numeric}, not silently
accepted as a proven invariant --- consistent with the epistemic
self-correction architecture discussed in Section~\ref{sec:selfcorrect}.

The end-to-end pipeline --- from raw ODE right-hand sides to
paper-ready catalog-routed proven invariants --- required
approximately $45$ seconds of CPU time with zero human intervention
beyond setting the integration interval and initial conditions for
each system. All code is open source and reproducible by running
\texttt{cargo run -p symthaea-physics-bridge --example ramanujan\_showcase --release}.
