# Demos

Demo applications showcasing Symthaea capabilities.

## Running Demos

```bash
# List available demos
ls demos/

# Run a specific demo
cargo run --example <demo_name>
```

## Available Demos

See `examples/` for the main collection of runnable demonstrations:

- `phi_engine_quick_demo.rs` - Quick Φ calculation demo
- `tier_3_exotic_topologies.rs` - Topology validation
- `brain_actor_model_demo.rs` - Brain subsystem demo
- `consciousness_observatory_demo.rs` - Consciousness monitoring

## Creating New Demos

1. Add to `examples/` directory
2. Register in `Cargo.toml` if needed
3. Document in this README
