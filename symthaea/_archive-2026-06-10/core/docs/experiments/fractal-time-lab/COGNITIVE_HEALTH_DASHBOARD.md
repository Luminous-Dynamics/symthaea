# Symthaea Cognitive Health Dashboard (v5.0)

## Executive Summary
The system's "Cognitive Health" is monitored in real-time via the Fractal Time Lab diagnostic suite. This dashboard synthesizes temporal stability, structural fidelity, and GWT-Reasoning coherence into actionable health metrics.

## Diagnostic Metrics (Health Scorecard)

| Metric | Origin | Diagnostic Utility |
| :--- | :--- | :--- |
| **Stability Index** | `TemporalStabilityDetector` | Detects persistent 2T resonance (crystalline reasoning) vs. decaying noise. |
| **Structural Fidelity** | `StructuralFidelityAudit` | Flags coherence anomalies in the reasoning stream. |
| **Cognitive Coherence** | `CognitiveCoherenceAuditor` | Measures coupling between GWT conscious ignitions and reasoning reliability. |

## Health Thresholds

| State | Stability Range | Fidelity Range | Coherence Range |
| :--- | :--- | :--- | :--- |
| **Stable** | > 0.6 | > 0.7 | > 0.6 |
| **Anomalous**| 0.3 - 0.6 | 0.3 - 0.7 | 0.3 - 0.6 |
| **Divergent**| < 0.3 | < 0.3 | < 0.3 |

## Alerting Criteria
- **Stability Alarm**: Triggered if persistence falls below 0.3 in any three consecutive cycles.
- **Fidelity Alert**: Triggered on immediate detection of a structural fidelity anomaly.
- **Coherence Drift**: Triggered if coupling between GWT and reasoning streams trends below 0.3 over a 128-cycle window.
