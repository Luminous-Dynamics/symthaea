# Neural Evidence Provenance v1

**Status:** qualification profile candidate  
**Scope:** Symthaea neural-validation bridges and benchmark inputs  
**Profile:** `symthaea-neuro-evidence-v1@1`

## Purpose

This profile prevents synthetic fixtures, simulated model states, external brain-encoding predictions, and observed neural recordings from being silently treated as interchangeable evidence.

The central rule is:

> Similar-looking neural data does not imply equal evidential authority.

TRIBE v2 is an external brain-encoding model. Its output is useful surrogate evidence for model-to-model alignment experiments, but it is not an observed fMRI recording from a participant. Synthetic fixtures are useful for deterministic software tests, but they are not neuroscience evidence.

## Evidence authorities

| Authority | Meaning | Example | May stand in for observed neural data? |
| --- | --- | --- | --- |
| `SyntheticFixture` | Deterministic or stochastic test data produced by Symthaea tooling | `tribe_v2_bridge.py --mock` | **No** |
| `SimulatedModel` | State generated by Symthaea or another explicit mechanistic simulation | Symthaea cortical activation telemetry | **No** |
| `ExternalSurrogate` | Prediction from an external model trained to predict neural data | TRIBE v2 fsaverage5 prediction | **No** |
| `EmpiricalObserved` | Neural data measured from a participant or organism with explicit dataset provenance | fMRI/EEG/MEG/iEEG recording | **Yes** |

## Coordinate-system rule

Every externally sourced neural representation must declare the coordinate system in which its values live.

The released TRIBE v2 model predicts `(n_timesteps, n_vertices)` on the `fsaverage5` cortical surface. Therefore a TRIBE v2 output is **not** a 360-element Glasser/HCP-MMP1 parcellation merely because the first 360 values can be sliced from it.

The valid future mapping chain is:

`TRIBE v2 fsaverage5 -> verified surface atlas mapping -> atlas parcels -> optional Symthaea12 projection`

Until that mapping is implemented and qualified, the bridge preserves native `fsaverage5` output and does not emit `region_activations` for real TRIBE inference.

## Normative invariants

### NEP-001 — Synthetic fallback is forbidden

If real external inference is requested and the external model or dependency is unavailable, the bridge must return an error. It must never replace the requested result with synthetic data.

### NEP-002 — Mock mode is explicit

Synthetic output may only be produced through an explicit mock/fixture request. Synthetic output must carry `source = SyntheticFixture` and `evidence_authority = SyntheticFixture`.

### NEP-003 — Synthetic schema is non-empirical

Synthetic regional fixtures must not use the empirical/surrogate loader field `region_activations`. The v1 bridge uses `synthetic_region_activations` so existing empirical loaders fail closed rather than consume fixture data accidentally.

### NEP-004 — Surrogate is not observation

External brain-encoding model output must be labeled `ExternalSurrogate`. It may be used for surrogate/model-alignment benchmarks, but it must not be represented as `EmpiricalObserved` or used as proof of an observed human neural response.

### NEP-005 — Native coordinates are preserved

A bridge must not relabel, truncate, reorder, or aggregate a neural representation into another coordinate system without an explicit, reviewed transformation.

### NEP-006 — Runtime import failure fails closed

Import or model-loading failure in real mode must produce a non-zero exit and no output artifact.

### NEP-007 — Fixture generation is reproducible

Given the same fixture stimulus identifier and profile, mock output must be identical across processes. Runtime-randomized language hashes are not acceptable seed material.

### NEP-008 — Provenance survives serialization

Every bridge artifact must preserve at least:

- `source`
- `evidence_authority`
- `model`
- `coordinate_system`
- `stimulus_id`
- the aggregation performed, if any

Real surface predictions additionally record the number of timesteps and vertices.

## Current v1 bridge behavior

### Real TRIBE v2

The bridge follows the released API:

```python
from tribev2 import TribeModel

model = TribeModel.from_pretrained("facebook/tribev2")
events = model.get_events_dataframe(video_path="stimulus.mp4")
predictions, segments = model.predict(events=events)
```

The bridge temporally averages the returned surface prediction while retaining `coordinate_system = fsaverage5` and the full vertex vector.

It deliberately does **not** emit a Glasser or Symthaea12 regional projection yet.

### Mock mode

Mock output is deterministic and carries a distinct field:

```json
{
  "source": "SyntheticFixture",
  "evidence_authority": "SyntheticFixture",
  "coordinate_system": "symthaea12",
  "synthetic_region_activations": {}
}
```

This is intentionally incompatible with the current `region_activations` empirical/surrogate loader path.

## Qualification tests

`scripts/test_tribe_v2_bridge.py` establishes four executable gates:

1. mock output is explicitly synthetic, ineligible for empirical/surrogate use, and cannot satisfy the existing `region_activations` schema;
2. mock output is reproducible across independent Python processes;
3. a stand-in implementing the released `tribev2.TribeModel` API proves native surface shape is preserved: a 2×4 prediction remains four `fsaverage5` vertices after temporal averaging and is emitted as `ExternalSurrogate`, never as 12-region data;
4. forced TRIBE import failure returns non-zero, produces no artifact, and does not fall back to mock data.

`.github/workflows/neural-evidence-provenance.yml` runs these tests plus Python syntax checks whenever the bridge, tests, profile, or workflow changes.

## Deferred to the next profile

This profile does not claim to solve:

- canonical Rust neural-evidence types in `symthaea-types`;
- `fsaverage5 -> HCP-MMP1/Glasser` surface parcellation;
- atlas-to-Symthaea12 scientific validity;
- real observed fMRI ingestion;
- observed EEG/MEG/iEEG ingestion;
- representational-similarity analysis;
- evidence-domain separation inside the Rust substrate/consciousness framework.

Those require separate patches so that bridge provenance correctness can be reviewed independently from neuroscientific transformation choices.

## Scientific boundary

Passing this profile means only that neural evidence authority and coordinate provenance are no longer silently laundered by the bridge.

It does **not** establish that Symthaea models the human brain, that TRIBE predictions are observations, or that neural similarity is evidence of consciousness.
