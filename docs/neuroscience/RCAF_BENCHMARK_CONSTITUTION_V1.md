# Repeatability-Calibrated Architecture Fidelity (RCAF) — Constitution V1

**Status:** Research benchmark proposal and published-analysis reproduction target. No new biological analysis has been run by this work item.  
**Date:** 2026-11-21  
**Parent:** Consciousness Evidence & Theory Benchmark (CETB) V1

## 1. Why this benchmark exists

A similarity or distance between two neural measurements is not interpretable against a perfect-match ceiling alone. The same state, measured twice, has estimation variability due to finite recording length, physiological fluctuations, artifacts, preprocessing and estimator uncertainty.

RCAF makes a within-state repeatability reference part of the benchmark itself. It asks whether an observed between-state difference exceeds the variability expected when the same operational state is measured repeatedly.

This is a measurement-validity benchmark. It does not infer phenomenal experience from connectivity, and it does not turn an observed state difference into a causal effect.

## 2. Core estimands

Let S(A,B) be a declared similarity measure on two estimates of the same representation, with larger values indicating greater similarity. For weighted Jaccard (WJ) on non-negative edge weights:

WJ(A,B) = sum_i min(A_i, B_i) / sum_i max(A_i, B_i)

The measure is undefined when both inputs have zero total mass; that condition must fail closed rather than return NaN or a fabricated zero.

For participant i:

- S_within_i: a participant-level summary of repeated measurements in the same declared condition.
- S_between_i: a participant-level summary of measurements across two declared conditions.
- gap_i = S_within_i - S_between_i.

Positive gap means between-state similarity is lower than the within-state reference. Report the full participant-level distribution, not only the cohort mean.

A normalized descriptive quantity may also be reported:

excess_distance_fraction_i = (S_within_i - S_between_i) / (1 - S_between_i)

This is an operational normalization of the gap against the observed between-state distance. It is **not** a variance decomposition, a causal attribution fraction, or a percentage of consciousness lost. It is undefined when S_between_i == 1. Do not label it “the percentage of the brain changed”.

Required primary outputs:

1. Within-state similarity distribution, per participant and per condition.
2. Between-state similarity distribution, per participant and per ordered comparison.
3. Paired gap distribution, with participant-level uncertainty interval.
4. Fraction of participants with positive gap.
5. Normalized excess-distance fraction, clearly labelled descriptive.
6. Sensitivity across predeclared estimator and preprocessing variants.
7. The raw per-participant records and complete denominator/exclusion flow.

Do not collapse the outputs into one RCAF score.

## 3. ds006623 published reanalysis to reproduce

A 2026 NeuroImage: Reports paper applied Weighted Jaccard similarity to the OpenNeuro ds006623 propofol fMRI data and added a within-condition floor after peer review. It reports:

- 26 participants in the dataset; two excluded for incomplete conditions, leaving N=24 in the main analysis.
- 23 participants with adequate data for all three conditions after the post-LOR trim and the two-segment requirement.
- 456 ROIs, Spearman correlation matrices and 300-volume segments.
- Five repeated segment draws per participant.
- Within-state WJ reference 0.544; the reported between-state similarities are lower.
- A group-averaging control and a participant-identity permutation control.
- Four sign treatments and stratified sign-flip rates.

The reported 0.544 is a paper result to reproduce, not a hard-coded expected output and not a universal repeatability constant.

The author's revision code states that the primary revised numbers are generated by revision/revision_final_trimmed.py, followed by revision/revision_group_artifact_fisherz.py. It explicitly rejects an odd/even-volume split as the within-state reference because adjacent fMRI volumes share temporal and hemodynamic structure.

## 4. Mandatory reproduction lane

The initial run must reproduce the author's code and method before introducing a new RCAF implementation.

Freeze:

- OpenNeuro dataset DOI, version, complete file manifest and SHA-256 digests.
- XCP-D derivative family, atlas, confounds, GSR choice, filtering and censoring.
- Participant/run inclusion and exclusion reasons.
- LOR timing source and post-LOR trimming convention.
- Common ROI labels and canonical parcel ordering.
- Correlation estimator and handling of non-finite/constant columns.
- Segment length, placement, repeat count and random seed.
- WJ transform (absolute, positive-only, negative-only or signed-shift).
- Statistical tests, bootstrap unit and multiplicity family.
- Exact analysis-code revision and environment lock.

The author's main revised floor protocol uses 300-volume segments and five repeats. Reproduce this first; do not silently replace it with a more attractive split.

## 5. Repeatability design: do not confuse more windows with more subjects

Within each participant and condition, sample non-overlapping segments with equal length. The author implementation samples two adjacent, non-overlapping 300-volume segments within each repeat. That exact convention belongs in the reproduction lane.

The extension lane must separately test whether the floor is sensitive to temporal adjacency:

- Reproduce the adjacent non-overlapping reference exactly.
- Add a predeclared guard interval between segments, where the run length permits.
- Add non-adjacent block pairs as a sensitivity analysis.
- Vary segment length only over values that fit the eligible runs and are frozen before inspecting the resulting contrasts.
- Preserve timestamps and acquisition order; do not interleave odd/even volumes.
- Do not treat five repeated segment placements as five independent participants.

The primary inferential unit remains the participant. Aggregate repeated segment draws within participant before cohort inference, or use a hierarchical model that explicitly represents nested measurements.

## 6. Required robustness battery

Run each variant as a separate labelled analysis. Never select the best-looking variant after seeing the result.

### Similarity and sign handling

1. Absolute-correlation WJ.
2. Positive-edge-only WJ.
3. Negative-edge-only WJ.
4. Signed-shift WJ with the exact transformation declared.

For positive-only and negative-only WJ, use the shared sign mask: include an edge only when it has the requested sign in BOTH compared matrices. Do not independently zero non-matching signs and then include those edges in the denominator; that is a different estimand. Record the minimum selected-edge count and fail closed when the mask is too sparse.
5. Direct sign-flip rates stratified by minimum edge magnitude.
6. Net-versus-gross redistribution index, with formula and interpretation.

### Estimator and preprocessing sensitivity

1. Spearman versus Pearson correlation.
2. XCP-D variants with and without global signal regression, where available and scientifically justified.
3. Filtering/censoring variants already present in the pinned derivatives.
4. Alternative predeclared ROI/parcellation choices where valid matching labels exist.
5. Motion-only and signal-quality-only controls.
6. Segment-length and temporal-gap sensitivity.

The 2026 TMS–EEG literature reports material sensitivity of some neurophysiological metrics to preprocessing and emphasizes inter-individual variation and lack of a fully harmonized end-to-end pipeline. This is why method variation must be measured rather than hidden behind one preferred pipeline.

### Group aggregation

Compare subject-level results with group-averaged matrices. Include a participant-identity permutation control. Group-level matrices are not a substitute for paired subject-level estimates.

### Inference

- Paired participant-level bootstrap confidence intervals.
- Paired permutation/sign-flip or a justified non-parametric paired test.
- Effect sizes and raw paired differences alongside p-values.
- Multiple-comparison control over the declared family of variants.
- Report the resolution limit of the test. With N=23, an exact two-sided sign-based p-value can saturate at 2/2^23; a boundary p-value must not be described as evidence of arbitrarily extreme certainty.
- Preserve all subjects, missing conditions, failed matrices, censored segments and exclusions in the run ledger.

## 7. Proposed RCAF qualification gates

These are proposed engineering/research targets, not results.

| Gate | Proposed criterion |
|---|---|
| Kernel correctness | Weighted-Jaccard implementation matches hand-computed fixtures and the pinned reference on the same edge arrays to numerical tolerance |
| Input validity | Reject non-finite, negative, mismatched or zero-mass edge vectors; reject asymmetric/misaligned matrices |
| Method reproduction | Recover the published summary outputs within a predeclared tolerance after exact input and preprocessing parity |
| Repeatability | Report within-condition distributions per condition, not only one pooled floor |
| Paired inference | Participant is the primary independent unit; repeats remain nested |
| Temporal validity | Adjacent-segment reproduction plus guard-gap/non-adjacent sensitivity |
| Pipeline robustness | Report all predeclared variants; target at least 90% directional agreement for a candidate robust effect, with no hidden variant selection |
| Group aggregation | Quantify aggregation inflation and retain subject-level results as primary |
| Replay | Independent clean-environment replay reproduces the run receipt and outputs |

A failure at one gate does not get averaged away by success at another.

## 8. Interpretation boundaries

RCAF can support a statement that a declared neural representation differs across declared conditions by more than its estimated within-condition repeatability under a specified measurement protocol.

RCAF cannot by itself establish:
- phenomenal experience, its absence or its intensity;
- that a particular neural pattern is sufficient or necessary for consciousness;
- a causal explanation of the transition;
- a universal threshold transferable between people, modalities or devices;
- clinical diagnostic performance.

## 9. Research extensions beyond the published reanalysis

1. **Repeatability surface:** estimate within-state similarity as a function of segment duration, temporal gap, motion and signal quality.
2. **Pipeline multiverse:** quantify how the effect changes across justified preprocessing/estimator choices; report the full envelope.
3. **Hierarchical uncertainty:** separate participant, session, run, segment and estimator variance instead of treating every window as independent.
4. **Temporal prediction:** test whether state transitions can be predicted before a behavioural transition, using only past observations and participant-held-out data.
5. **Cross-modal transport:** test whether an effect survives when evaluated using independently acquired EEG or TMS–EEG data. This is an external validation lane, not a dataset merge.
6. **Active acquisition:** select the next segment or modality by expected reduction in decision-relevant uncertainty, not by generic information gain alone.

## 11. RCAF v1.1: participant sign test and polarity transitions

The standalone kernel now includes two complementary diagnostics.

### Exact participant-level sign test

For participant-paired gaps g_i = S_within,i - S_between,i, count positive, negative and exactly zero gaps. Exclude exact-zero ties from the binomial denominator and compute the two-sided exact sign-test probability under equal positive/negative sign probability.

This is a distribution-free test of a zero median under independent participant pairs. It is not a randomized treatment-assignment test, does not establish causality and does not replace the effect distribution or confidence interval. Report positive, negative, tie and non-tied counts with the p-value. Near-zero differences are not silently treated as ties; any equivalence margin must be separately prespecified.

The exact sign test complements the participant bootstrap. At small N, its p-value has coarse resolution; for N=23 all 23 non-tied gaps in one direction yield 2/2^23, and no stronger exact two-sided sign-test result is possible for that N.

### Direct edge-sign transitions

Pair-aware positive-only and negative-only WJ deliberately compare only edges having the same requested sign in both matrices. This avoids treating a polarity-reversed edge as a zero-weight member of the selected-sign denominator, but means the WJ subset does not itself quantify reversals.

Therefore each matrix comparison must also report:
- positive-to-negative and negative-to-positive reversals;
- positive/negative-to-neutral and neutral-to-positive/negative transitions;
- stable positive, negative and neutral edge counts;
- polarity-reversal and total sign-state-change fractions;
- the predeclared neutral-band threshold and a sensitivity grid.

A matrix's dimension does not prove its ROI ordering. Bind each matrix to a canonical ROI label/order digest and reject comparisons if the labels or order differ. Report selected-edge counts for every WJ mode.

### Machine-readable report

research/rcaf/rcaf-report.schema.json defines the participant-level output contract, including source/access state, acquisition/release/QC/analysis denominator flow, frozen estimator/preprocessing, ROI-order digest, participant-level summaries, sign-test results, bootstrap interval and explicit claim limits. The fixture at research/rcaf/fixtures/synthetic-rcaf-report.json is synthetic only.

## 12. Quality-aware measurement extensions

The 2026 Network Similarity Index (NSI) offers an external quality-assessment comparator for precision functional mapping. CETB should evaluate it where individual functional-connectivity mapping assumptions fit, and should treat it as an optional quality covariate—not a universal gate across task-fMRI, anesthesia, EEG or iEEG.

The 2025 239-statistic functional-connectivity benchmark shows that estimator choice changes network properties, identifiability and prediction. RCAF must therefore keep WJ as one estimator within an objective-matched estimator tournament. Compare Pearson/Spearman, covariance/precision and graph/network measures under frozen analysis variants; do not use the best-performing estimator selected on the final test cohort.
