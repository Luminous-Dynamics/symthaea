## 1. General joint-DGP object

The cross-covariance nuisance is now represented directly by a linear operator

`E[e | q] = K q,`

`Var(e | q) = Sigma_e - K Sigma_q K'`

for an explicit stacked multi-channel innovation vector `q`.

The executed stress uses three innovation channels with block-diagonal `Sigma_q` and a fixed marginal outcome covariance `Sigma_e` generated by the declared AR(0.5)+heteroskedastic loading. The operator `K` contains contemporaneous, cross-channel, one-lag, and distributed-lag structures.

The operator-strength normalization is

`||Sigma_e^{-1/2} K Sigma_q^{1/2}||_2 = strength`

so `strength^2` is the maximum explained-covariance fraction under the fixed marginal `Sigma_e`. All executed strengths are below one, so the conditional covariance remains positive definite.

## 2. Universal conditional-risk identity

For a fixed feature path, fixed training standardization, fixed ridge value, and fixed rolling forecast operators, each model's forecast-error mean is affine in the relational coefficient vector `gamma` and the cross-covariance operator `K`.

For origin `o`, write the conditional forecast-error mean for model `m` as

`r_m(gamma,K) = W_m [mu0_tr + Z_tr gamma + K q_tr] - [mu0_te + Z_te gamma + K q_te].`

With

`V = Sigma_e - K Sigma_q K',`

the conditional expected squared-error risk is

`R_m = H^{-1} [ ||r_m||^2 + tr(W_m V_tt W_m') + tr(V_yy) - 2 tr(W_m V_ty) ].`

For the paired context-minus-relational loss, the common `tr(V_yy)` term cancels.

This gives the structural result:

> For arbitrary fixed linear `K`, the finite-sample accuracy null remains quadratic in `gamma`.

More strongly:

> If `K(theta) = K0 + sum_j theta_j K_j` is affine in nuisance coordinates and `Sigma_e`, `Sigma_q`, the feature path, and forecast operators are fixed, then the conditional finite-sample loss surface is polynomial of total degree at most two jointly in `gamma` and `theta`.

The joint polynomial can contain `gamma-theta` cross terms and `theta-theta` terms. It is therefore not generally separable.

## 3. Scalar-strength slices are now a theorem, not a construction artifact

For any fixed operator direction `K1`, set

`K(s) = s K1.`

Then

`Delta(gamma;s) = gamma' Q gamma + (b0 + s b1)' gamma + c0 + s c1 + s^2 c2.`

Thus the earlier scalar-`omega` quadratic dependence is not specific to the shared-shock finite-rank family. It is the generic consequence of an affine one-dimensional operator path with fixed marginal covariance.

What remains non-universal is the mapping from the scientific nuisance object `K` to the coefficients `b0,b1,c0,c1,c2`, including channel and lag geometry.

## 4. Exact topology theorem remains conditional only on Q curvature

For `Delta(tu)=A t^2+B t+C` with `Q >> 0`:

- `C < 0`: every direction has positive discriminant and exactly one positive root.
- `C = 0`: the nonzero positive branch is the `b'u < 0` hemisphere.
- `C > 0`: `R = bb' - 4 C Q` has at most one positive eigenvalue, and global real-root support exists iff `b' Q^{-1} b > 4 C`. Positive-root support is the discriminant cone intersected with `b'u < 0`.

This theorem is algebraic. The generalized-`K` result shows that the theorem is not tied to a finite-rank endogeneity recipe; only the nuisance-to-surface map is recipe-dependent.

For weak or indefinite `Q`, the exact theorem is not applied.

## 9. Scientific consequence

The correct generalized state is now:

`K` + `Sigma_q` + `Sigma_e` + `Q` curvature + discriminant topology + branch conditioning + effect radius.

The previous scalar-`omega` construction is therefore best understood as one coordinate chart through this larger nuisance space, not as the nuisance space itself.

The strongest new universal statement is narrower and cleaner:

> Joint-law endogeneity does not by itself destroy quadraticity in the finite-sample relational coefficient vector when the estimator remains fixed-feature linear and the cross-covariance enters through a linear conditional mean with the covariance completion `Sigma_e-K Sigma_q K'`.

What it does change is the nuisance location of the null surface and its branch geometry.
