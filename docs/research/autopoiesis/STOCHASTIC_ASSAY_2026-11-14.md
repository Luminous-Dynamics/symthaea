# AOBench stochastic categorical assay evaluation v0.1

**Status:** Initial exact finite-sample evaluator; exact-head qualification required  
**Tracking:** [#12048 — stochastic assay response distributions](https://github.com/Luminous-Dynamics/symthaea/issues/12048)  
**Implementation:** `crates/domains/symthaea-organizational-closure/src/stochastic_assay.rs`

## 1. Why this exists

The deterministic assay evaluator compares a single response digest per candidate model and assay. That is useful for deterministic fixtures, but a digest inequality is not a statistical distinguishability test for stochastic systems.

Segura (2026) distinguishes the natural organization, a formal organizational surrogate and the response profile produced by a finite protocol family. Equivalence of restricted profiles only supports organizational equivalence when the protocol family is conservative over a declared candidate class:

- https://doi.org/10.1016/j.biosystems.2026.105928

AOBench therefore keeps deterministic signatures and stochastic response distributions as separate methods.

## 2. Exact v0.1 scope

The initial implementation supports:
- categorical outcomes;
- independent replicate observations;
- two-sample exchangeability/permutation tests;
- total-variation distance as the effect statistic;
- exhaustive enumeration of all allocations, bounded by an explicit maximum;
- Holm step-down family-wise correction across every registered non-equivalent model-pair × assay comparison;
- a pre-registered minimum practical effect threshold.

It does not yet support:
- paired or matched-seed permutation tests;
- clustered or temporally dependent samples;
- continuous/multivariate outcomes;
- sequential monitoring or optional stopping;
- confidence intervals or formal power analysis;
- adaptive assay selection;
- physical or biological measurement adapters.

In particular, the permutation null assumes that the observed categorical replicates are independently exchangeable between the two candidate models under the null. Do not apply it to matched or autocorrelated trials.

## 3. Frozen statistical contract

A run supplies:
- a finite candidate model set and target equivalence classes;
- registered assay IDs;
- trial-level observations with model, assay, trial ID, status and optional categorical outcome;
- alpha, minimum total-variation effect, minimum sample count and permutation budget.

The analysis does not count missing, failed or censored observations as an outcome. They remain separate trial statuses and reduce the number of observed samples available for that comparison.

For each non-equivalent model pair and registered assay, let (P) and (Q) be empirical categorical response distributions. The effect statistic is total variation:

[
D_{TV}(P,Q)=\frac{1}{2}\sum_x |P(x)-Q(x)|.
]

The exact null distribution is generated by allocating the pooled labelled outcomes into two groups of the original sample sizes. Every allocation is enumerated. The exact p-value is the fraction of allocations whose total-variation statistic is at least as large as the observed statistic.

If the number of allocations exceeds the declared budget, the result is `Inconclusive`. It is not approximated and is not called a failure or equivalence.

## 4. Multiplicity and conservative-panel semantics

The family consists of every planned pair × registered assay for candidate pairs in different target-equivalence classes.

Holm correction is applied across that whole family. Underpowered and budget-inconclusive comparisons are retained as p=1 placeholders in the family size, but they remain individually `Underpowered` or `Inconclusive`.

A comparison is `Distinguishable` only when both conditions hold:
1. Holm-adjusted p-value is at or below the frozen alpha.
2. Observed total-variation effect meets or exceeds the frozen minimum practical effect.

A comparison that does not meet the threshold is `NotDistinguished`, not “equivalent.” A model pair is resolved if at least one registered assay distinguishes it. The assay family is conservative only when every target-non-equivalent pair is resolved and no invalid evidence findings remain.

## 5. Deterministic controls

The initial tests cover:
- clearly separated response distributions;
- identical empirical distributions;
- missing/failed trials not counted as zero outcomes;
- permutation-budget exhaustion;
- Holm correction using the complete planned comparison family;
- target-equivalent models not creating required separation tests;
- duplicate trial IDs blocking conservative qualification.

The perfectly separated four-versus-four fixture has 70 possible allocations. Only two reach the observed maximum total-variation statistic, giving exact p=2/70 before multiplicity correction. This is a fixture-level test, not a benchmark result.

## 6. Remaining statistical work

Before using this evaluator for noisy real-world systems, add and qualify:
- exact confidence intervals for effect estimates;
- power and minimum-detectable-effect planning;
- paired/block permutation tests for matched seeds and temporal dependence;
- a deterministic, reproducible Monte Carlo path for large permutation spaces;
- multiplicity families spanning confirmatory outcome variables;
- missingness sensitivity and censored/failed-trial policy;
- calibration on synthetic null and positive-control distributions;
- a machine-readable result manifest binding samples, candidate class, analysis plan, implementation revision and verifier.

Do not select alpha, effect threshold, assay panel or stopping rule after inspecting confirmatory outcomes.

## 7. Claim boundary

This module evaluates whether a finite registered assay panel distinguishes a finite frozen candidate model class under a specified statistical contract. It does not prove that the candidate class is exhaustive, establish universal model equivalence, identify biological autopoiesis, or measure life, sentience or consciousness.
