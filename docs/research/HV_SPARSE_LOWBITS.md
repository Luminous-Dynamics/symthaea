# Sparse and low-bit HDC candidate matrix

Research-only qualification contract for sparse binary, sparse bipolar, ternary, int2/int4/int8 and sparse-block candidates.

Each candidate must declare domain, dimension, density/quantization, storage, metric, binding, bundling, permutation, deterministic generation, serialization, conversion rules and exact/approximate invariants.

Measure matched-quality task performance, resident bytes, materialization bytes, bytes moved, allocations, latency and robustness. Explicitly detect dense fallback and hidden conversion. Unsupported cells are unknown/N/A, not zero.
