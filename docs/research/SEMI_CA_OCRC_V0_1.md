# SEMI-CA-OCRC-001 — capacity-aware delayed online conformal risk control v0.1

**Issue:** #13645  
**Implementation:** symthaea-semiconductor::benchmark::ca_ocrc  
**Status:** bounded-arbitrary-delay reference implementation with authored Rust tests; exact-head validation pending.

## Research anchor and scope

Wang & Simeone, *Capacity-Constrained Delayed Feedback for Online Conformal Risk Control*, arXiv:2611.17059 (2026-11-12): https://arxiv.org/abs/2611.17059.

This version reproduces the paper's **arbitrary bounded-delay** CA-OCRC path. It does not implement the stochastic-delay G-aware optimization from Section VI.

The theoretical setting assumes a pre-trained predictor with score S_t(X_t,y) in [0,B], prediction set C_t={y:S_t(X_t,y)<=r_t}, loss L_t in [0,1], L(empty,y)=1 and L(full,y)=0, arbitrary data/loss sequences, and true feedback delays 0<=d_t<=d_max. The learner can track at most K pending feedback outcomes continuously.

## Implemented equations

Proxy delay dbar_t has support {-1,0,...,d_max}. The survival table F(a)=P(dbar>=a) is supplied in the policy and must be non-increasing:
- P(dbar=-1)=1-F(0)
- P(dbar=a)=F(a)-F(a+1), for 0<=a<d_max
- P(dbar=d_max)=F(d_max)

The uniform draw is supplied by the caller and recorded. No PRNG state or entropy is generated inside the pure reference replay.

At round t:
1. The caller declares the prediction-set kind; it must match the threshold r_t. Nontrivial sets require a uniform proxy-delay draw. Empty/full sets have known loss and consume no tracking slot.
2. Evict tracked i iff i+dbar_i<t. Thus a feedback event at age exactly dbar_i is still receivable on that round.
3. Sample dbar_t; admit t iff dbar_t>=0 and the post-eviction tracking set has capacity.
4. Process all feedback events arriving at t that remain tracked.
5. Update the threshold.

The exact threshold update for arbitrary bounded delays is:

r_(t+1)=r_t + eta*phi_t*(L_t-alpha)
        + eta*sum_(i in O_t) (L_i-alpha)/F(d_i),

where phi_t=1 for trivial empty/full prediction sets and 0 otherwise; O_t is the set of tracked feedback signals received on round t. In this bounded arbitrary-delay case q_G(d_max)=1. No clipping is introduced beyond the paper's equations; threshold values below zero or at/above B yield empty/full sets, whose losses are known.

The underload quantity is ell_F=sum_(a=1..d_max) F(a), constrained to ell_F<=K.

The code exposes the paper's arbitrary-delay bound:

RiskGap(T) <= B/(eta*T)
             + (K+1)/(F(d_max)*T)
             + exp(-K*h(ell_F/K)),

h(x)=x-1-ln(x).

The implementation returns no theoretical bound after a tracked feedback event is excluded as UNKNOWN/BLOCKED, because qualification missingness is not covered by the delay-only theorem.

## Optimized worst-case proxy family

The implementation also includes a deterministic golden-section optimizer for the paper's worst-case family:
- F(0)=1;
- F(a)=p for 1<=a<=d_max;
- 0<p<=min(1,K/d_max).

It minimizes the paper's one-dimensional objective:
(B/(eta*T)) + ((K+1)/(p*T)) + exp(-K*h(d_max*p/K)).

The optimizer returns p, the complete survival table, tracking load and all risk-bound terms. This is a numerical minimizer over the analytic one-dimensional family, not a replacement for the paper's theorem or assumptions.

## Evidence separation

Two mechanisms remain distinct:

**Tracking loss** is generated by the randomized proxy horizon and capacity: proxy delay -1, capacity-denied admission, or proxy expiry. This is what the CA-OCRC theorem models and corrects.

**Qualification loss** occurs when a physical result is UNKNOWN or BLOCKED. This is an extra, potentially outcome-dependent selection mechanism. The implementation releases the tracking slot, records the exclusion, does not consume a loss value, and marks theorem assumptions as no longer intact. It does not set a missing outcome to zero, apply improvised IPW, or claim the paper's guarantee for the qualified-only stream.

The separate population-selection issue #13646 specifies audit-based and partial-identification methods for this second mechanism.

## Authored tests

The module currently contains tests for:
- exact inverse-CDF draw from a survival table;
- capacity never exceeding K and capacity denial;
- expiry before admission, with same-round slot reuse;
- feedback received at age exactly equal to proxy delay;
- inverse-probability weight uses F(actual_delay);
- UNKNOWN/BLOCKED never change the threshold and invalidate theorem status;
- trivial empty/full sets use known losses without tracking;
- post-expiry feedback is not tracked or applied;
- malformed/non-monotone/overloaded survival functions reject;
- weighted correction overflow leaves live engine state unchanged;
- deterministic replay for a fixed draw schedule;
- risk-bound term reporting;
- feedback input order canonicalizes to the same receipt.

## Benchmark matrix

Compare on identical synthetic loss/delay streams:
- unlimited OCRC (K>=d_max+1);
- intermittent OCRC (K=1);
- CA-OCRC with the paper's optimized worst-case proxy family;
- fixed-p CA-OCRC oracle selected on validation only;
- FIFO, random admission and naive drop-feedback as non-theoretical baselines.

Vary T, K, d_max, delay distribution, temporal dependence, loss process and fixed draw seeds. Report risk gap, interval/set width, tracking load, occupancy, saturation, proxy expiry, admission rate, inverse-probability weight tails, effective sample size and convergence.

Do not pool the theorem-valid CA-OCRC runs with evidence-excluded qualified-only runs. The latter require separate missingness analysis and carry no inherited CA-OCRC theorem claim.

It does not implement stochastic-delay CA-OCRC, does not establish population coverage after selective metrology qualification, and does not authorize wafer disposition, recipe/APC updates or equipment control.
