# HIST-CAUSAL-001 Protocol v0.1

Synthetic design validation and preregistration draft. No physical result is claimed.

This benchmark distinguishes local memory, common causes, conventional transfer, relational grammar, source-bounded construction order, and a separate history-effect model. It evaluates randomized interventions and requires abstention when models are not identifiable.

A research-only simulation found 20.4% false positives when participants were incorrectly treated as independent, versus 4.5% when the randomized task-family unit was used. This is synthetic design evidence only.
