# REL-005A — Graft Frame Qualification

Date: 2026-09-14
Authority: MeasurementOnly
Tracks: #3090, #3014

## Question

Qualify the existing `SwarmCoalition::compute_xenobot_graft_transform` and `translate_foreign_hypervector` APIs without changing production behavior.

The current mechanism estimates an elementwise multiplicative mask from paired anchors:

`F_T(x) = x .* T`.

REL-005A asks exactly which claims that mechanism supports.

## Positive-domain hypothesis

The primary qualification fixture stays entirely inside `ContinuousHV`'s documented nominal `[-1,1]` value range.

For construction anchors satisfying

`target_i = source_i .* T`

with one shared mask `T` and every source component safely outside the reciprocal floor, the production estimator should recover `T`, translate held-out vectors, compose across frames, and close an A→B→C→A loop within `1e-5`.

Frozen masks:

`T_AB = [0.5, -0.75, 0.9, -0.85, 0.8, -0.7, 0.95, -0.6]`

`T_BC = [-0.8, 0.7, -0.9, 0.65, 0.6, 0.75, -0.85, 0.9]`

All positive construction-source components have magnitude at least `0.35`; all positive sources and transformed targets remain in `[-1,1]`, and the positive construction corpus has zero coordinates below the reciprocal floor.

## Anchor-consistency diagnostic

The production implementation computes one implied mask per anchor pair and then bundles/averages them. REL-005A therefore measures the dispersion of those implied masks around the returned estimate.

Under the true shared-mask hypothesis, max dispersion must remain within `1e-5`.

Shuffled correspondences, mixed masks, and a corrupted anchor must produce max dispersion greater than `0.10` on the frozen fixtures. This records the information that the current `Option<ContinuousHV>` return type discards and gives REL-005B a measured basis for later fail-closed validation.

## Transported structure

The multiplicative frame action preserves some structures without changing their operator and transports others into dressed operators.

Bundling is linear under a fixed diagonal mask, so REL-005A requires

`F_T(bundle(x,y)) ~= bundle(F_T(x), F_T(y))`

within `1e-5`.

The source Hadamard identity `1` is transported to the target-frame identity `T`. REL-005A checks both `F_T(1) ~= T` and the corresponding dressed-unit action.

The fixed Hadamard product is not generally invariant:

`F_T(x .* y) != F_T(x) .* F_T(y)`.

On the frozen in-domain fixture, the fixed-Hadamard covariance defect must be greater than `1.2`.

The transported product is

`a star_T b = a .* b .* inverse(T)`.

The positive covariance theorem is

`F_T(x .* y) ~= F_T(x) star_T F_T(y)`

with defect at most `1e-5`.

Ordinary cosine is also not required to be invariant. The frozen in-domain fixture must exhibit raw cosine drift greater than `0.25`, while the pulled-back observable

`cos(a .* inverse(T), b .* inverse(T))`

must recover source-frame cosine within `1e-5`.

## Frame composition and loop consistency

REL-005A requires:

- direct A→C recovery;
- `T_AC ~= T_AB .* T_BC`;
- direct/sequential held-out transport agreement;
- an independently estimated C→A transform;
- A→B→C→A loop closure within `1e-5`.

The loop residual is a representation-frame consistency/holonomy diagnostic, not evidence of physical gauge curvature.

## Negative and stress controls

The executable contract records raw error for:

- shuffled anchor correspondence;
- anchor pairs generated by different masks;
- one corrupted anchor pair;
- a foreign coordinate below the production reciprocal floor;
- coordinate reversal, which lies outside the multiplicative-mask family;
- dimension mismatch, which currently reaches a production assertion;
- empty and unequal anchor counts, which currently return `None`;
- non-finite anchor content, which the current API is expected to propagate into a non-finite transform rather than reject.

Negative controls pass by being detectably wrong. Cleanup is not an authority for this tranche.

## Numerical validity boundary

`ContinuousHV::inverse()` maps components with `abs(v) < 1e-7` to zero. REL-005A records the affected-coordinate count/rate and requires the near-floor fixture to exhibit material held-out error.

Success away from this floor must not be generalized across it.

- Held-out transport does not imply fixed-operation invariance.

- Inconsistent anchors remain a measured limitation for REL-005B rather than being repaired here.
