# Alternative Economic Mechanism Registry — v0

**Status:** research substrate  
**Scope:** comparative institutional/economic simulation  
**Non-goal:** ideological ranking

This registry extends the Creditism research program into a common mechanism space. A model enters the registry because it is specified enough to test, not because it is assumed to be desirable or correct.

## Why add other models?

Creditism currently provides an unusually useful counterfactual because it changes monetary settlement, contribution recognition, and the relation between access signals and producer revenue. But a laboratory becomes much more informative when several independent architectures are represented.

The comparison should therefore avoid asking:

> Which system is best?

and instead ask:

> Under the same shock, information constraints, governance constraints, and inherited state, which mechanisms produce which observable consequences?

The laboratory should preserve mechanism differences rather than normalize them away.

## Inclusion gate

A candidate should be machine-profileable when the source material gives enough structure to specify most of:

1. production and enterprise decision rules;
2. ownership and control;
3. allocation/coordination;
4. financial or accounting mechanism, when applicable;
5. distribution;
6. governance and authority;
7. investment/capital formation;
8. scarcity and information handling;
9. persistence/transition;
10. identifiable failure modes or empirical evidence.

A policy instrument alone is not a system profile. Examples:

- Job Guarantee = macro-labour treatment;
- tax = distribution treatment;
- subsidy = price/incentive treatment;
- Doughnut indicators = objective/measurement layer.

Those can still be composed with system profiles.

## First serious candidate set

| Candidate | Primary divergence | Classification |
|---|---|---|
| Creditism | non-transferable/purpose-typed credit + contribution recognition | financial/settlement architecture |
| Sovereign Money / 100%-Money | transaction-money issuance separated from bank lending | monetary/banking architecture |
| Islamic risk-sharing finance | risk-sharing and asset-backed contracts in place of interest-centered risk transfer | financial architecture |
| Market Socialism | social/worker ownership with market allocation | ownership + allocation |
| Democratic negotiated planning | negotiated multi-level planning with local autonomy | coordination/planning |
| Participatory Economics | participatory councils + negotiated plans | coordination/distribution |
| Distributed Commonist Planning | in-kind mediation + distributed production protocols | coordination/planning |
| Community Wealth Building | local ownership, anchor procurement, wealth retention | place-based institutional architecture |
| Post-growth / Degrowth | ecological throughput and social sufficiency as binding macro concerns | macro objective/constraint |
| Polycentric Commons | nested autonomous governance of shared resources | governance overlay |
| Participatory Socialism | co-determination + broad capital circulation + public provision | ownership/distribution |
| Social Dividend Socialism | participatory planning + social dividend replacing wage as primary distribution | planning/distribution variant |
| MMT + Job Guarantee | sovereign fiscal-monetary framework + employment stabilizer | macro-fiscal regime |

## Priority for implementation

The highest-value first wave is:

### A. Sovereign Money / 100%-Money

Core experiment:

- separate money issuance from lending;
- preserve identical real-sector investment demand;
- compare deposit creation, credit rationing, bank-run exposure, shadow-banking migration, and transition costs.

Required adversaries:

- liquidity shock;
- deposit run;
- credit crunch;
- profitable but socially low-value lending;
- migration into off-balance-sheet credit;
- legacy-deposit conversion.

Recent analytical work on sovereign money explicitly revisits the 100% Money architecture and the separation between transaction money and bank loans.

Source:
https://www.tandfonline.com/doi/full/10.1080/00213624.2025.2455643

### B. Market Socialism / Cooperative Ownership

Core experiment:

- preserve competitive price formation;
- change firm control and ownership;
- keep technology and demand equal;
- observe capital formation, labour allocation, investment horizon, governance overhead, innovation, entry/exit, and inequality.

Do not assume worker ownership implies equality, efficiency, or resilience.

Source frontier:
https://journals.sagepub.com/doi/10.1177/1470594X251387579

### C. Democratic Negotiated Planning

Core experiment:

- decentralized information;
- local enterprise autonomy;
- negotiated plans across levels;
- hard/soft constraints;
- repeated re-planning under shocks.

Measure:

- convergence time;
- information loss;
- coordination workload;
- bottleneck propagation;
- revision latency;
- strategic reporting.

Source:
https://academic.oup.com/policy-press-scholarship-online/book/61193

### D. Participatory Economics

Core experiment:

- nested councils;
- negotiated consumption/production proposals;
- work allocation rules;
- participatory planning.

Measure:

- proposal burden;
- convergence;
- strategic inflation;
- representation quality;
- minority protection;
- computational cost.

This should remain distinct from generic democratic planning because the institutional mechanics differ.

### E. Distributed Commonist Planning

Core experiment:

- remove monetary/value mediation from the coordination path;
- model material-flow requirements directly;
- connect semi-autonomous producers via explicit protocols.

Measure:

- protocol complexity;
- supply-chain synchronization;
- resource bottlenecks;
- non-price scarcity information;
- externality handling;
- coordination under incomplete information.

Source:
https://academic.oup.com/policy-press-scholarship-online/book/61193

### F. Islamic Risk-Sharing Finance

Core experiment:

- compare interest-centered debt contracts with asset-backed and profit/loss-sharing contracts;
- keep the underlying real projects and shocks equal.

Measure:

- leverage;
- default incidence;
- who absorbs shocks;
- maturity mismatch;
- liquidity;
- monitoring burden;
- systemic contagion;
- migration toward debt-like instruments.

A 2025 study using 376 conventional and Islamic institutions across 12 countries reports different systemic-risk and spillover patterns, making this more than a purely theoretical comparator.

Source:
https://link.springer.com/article/10.1007/s11156-025-01413-5

## Second-wave profiles

### Community Wealth Building

Treat CWB as a place-based architecture built around local/community ownership, anchor institutions, procurement, and local wealth retention.

Key experiments:

- local multiplier vs capital leakage;
- procurement network resilience;
- worker/community ownership;
- access to capital;
- place-based lock-in;
- decarbonization coordination.

Recent 2026 work explicitly develops CWB as an evolving local-development model connected to just transition.

Source:
https://www.sciencedirect.com/science/article/pii/S2210422425001157

### Post-growth / Degrowth

Do not encode "degrowth" as merely lower GDP.

Instead encode:

- ecological throughput;
- energy/material constraints;
- investment and depreciation;
- social floor;
- labour transition;
- distribution;
- fiscal dynamics.

Recent work includes both stock-flow-consistent and three-sector macroeconomic formulations, which makes deterministic simulation substantially more plausible than slogan-level modelling.

Sources:
https://www.sciencedirect.com/science/article/pii/S0921800925001831
https://doi.org/10.1016/j.sftr.2026.101802
https://www.nature.com/articles/s41586-025-09385-1

### Polycentric Commons

Use as a governance architecture rather than pretending it is a full macroeconomic replacement.

Encode:

- resource boundaries;
- nested governance;
- local rule adaptation;
- monitoring;
- graduated sanctions;
- federation;
- inter-community coordination;
- institutional learning.

Source:
https://link.springer.com/article/10.1007/s11213-025-09712-7

### Participatory Socialism / Piketty

Encode:

- co-determination;
- progressive wealth/inheritance taxation;
- capital endowments;
- public services;
- circulation of property;
- market allocation.

Measure:

- capital concentration;
- voting concentration;
- worker power;
- inheritance effects;
- capital-flight pressure;
- intergenerational mobility.

Source:
https://plato.stanford.edu/archives/fall2025/entries/socialism/

### Social Dividend Socialism

Treat as a variant of participatory planning, not necessarily a separate first-class family.

Key divergence:

- social dividend as the primary distribution mechanism;
- reduced dependence on wage labour.

Measure:

- labour supply;
- unpleasant-task allocation;
- shirking;
- autonomy;
- consumer demand;
- coordination under decoupled contribution and consumption.

Source:
https://academic.oup.com/policy-press-scholarship-online/book/61193

### MMT + Job Guarantee

Treat this as a macro-fiscal regime rather than a full theory of ownership or allocation.

Measure:

- fiscal/monetary coordination;
- resource constraints;
- inflation;
- automatic stabilization;
- wage-floor effects;
- operational central-bank autonomy;
- external/FX limits.

Source:
https://link.springer.com/article/10.1057/s41302-025-00300-0

## Common profile contract

Every model profile should answer:

### Money and settlement
- who can create the settlement medium?
- what creates/retire units?
- who bears monetary risk?
- is money transferable?
- what extinguishes obligations?

### Ownership and control
- who owns productive assets?
- who votes?
- who appoints management?
- who captures residuals?
- what prevents control concentration?

### Allocation
- market;
- negotiated plan;
- administrative allocation;
- commons governance;
- protocol/in-kind allocation;
- hybrid.

### Investment
- retained earnings;
- debt;
- equity;
- public pool;
- social dividend;
- planned capital budget;
- other commitment mechanism.

### Labour
- wage;
- cooperative membership;
- social dividend;
- participatory assignment;
- voluntary contribution;
- guaranteed employment.

### Scarcity and information
- price;
- queue;
- explicit demand;
- material-flow signal;
- administrative priority;
- public planning signal;
- decentralized commons signal.

### Governance
- operational authority;
- collective-choice authority;
- constitutional authority;
- emergency authority;
- amendment path;
- contestability.

### Transition
- legacy debt;
- legacy equity;
- contracts;
- property;
- currency;
- banking;
- external trade obligations;
- stranded assets;
- reversibility.

### Persistence
- institutional memory;
- expectations;
- learning;
- network effects;
- switching costs;
- lock-in.

## Matched adversarial battery

Every model should face the same scenario families:

- demand shock;
- supply shock;
- credit crunch;
- bank failure;
- asset-price bubble;
- information asymmetry;
- strategic misreporting;
- monopoly/oligopoly;
- capital flight;
- ecological boundary;
- demographic shock;
- governance capture;
- corruption;
- emergency rule;
- legacy-transition shock;
- external trade/FX shock;
- metric gaming;
- self-fulfilling expectation;
- self-negating expectation.

A model must not receive a favorable scenario distribution because it is easier to represent.

## Comparison semantics

Preserve the following distinctions:

model identity
!= mechanism identity
!= policy treatment
!= scenario treatment
!= observed outcome

And:

specified
!= implemented
!= frozen-scenario surviving
!= empirically validated
!= historically feasible
!= politically legitimate
!= universally superior

## Strongest research payoff

The most valuable thing this registry adds is not a larger list of ideologies. It creates **orthogonal counterfactuals**.

For example:

- Creditism vs Sovereign Money changes the money-creation mechanism while keeping other layers fixed as far as possible.
- Creditism vs Market Socialism changes ownership/control.
- Creditism vs Democratic Planning changes coordination.
- Creditism vs Islamic Finance changes risk allocation and contract structure.
- Creditism vs Commonist Planning changes the mediation/accounting layer.
- Creditism vs Degrowth changes the macro objective/constraint.
- Any of these can then be composed with Polycentric Commons governance and institutional-evolution machinery.

That composition should let the laboratory test which claimed benefits come from the named system and which come from an orthogonal mechanism that could be transplanted elsewhere.

## Claim ceiling

A model profile is not an advocacy claim.

A deterministic PASS should establish only the exact semantics covered by the frozen fixtures and implementation. Real-world comparison requires separate empirical evidence, and historical/political claims must remain outside synthetic qualification.
