# Gate 2: hard phonetic suite (2026-07-28)

Per the reviewer's recommended sequence: reuse ACE-Step v1's Gate D
phrase set (`../../controllability-gate-d/`) through the fixed
Kokoro+WORLD-vocoder pipeline (v2, phoneme-aware retiming), for a direct
capability-boundary comparison across two structurally unrelated
backbones.

## Setup

Same 10 phrase categories/texts as Gate D (positive_control,
conversational, repeated_syllables, rapid_letter_names,
phrase_final_stops, fricative_heavy, consonant_clusters,
long_sustained_vowels, short_unstressed, semantically_unusual). Melody:
a simple 5-note pentatonic-ish cycle (C4/D4/E4/G4/A4) assigned one note
per word, cycling for longer phrases — chosen to avoid hand-tuning bias
per phrase, not because it's musically ideal. **n=1 trial per phrase**,
not Gate D's 3 seeds — see "Scope" below for why this is a meaningful
difference from Gate D, not just a corner cut.

## The notable finding: real overlap with ACE-Step v1's own capability boundary

Despite being a completely different backbone (word-level Kokoro TTS +
WORLD-vocoder reshaping vs. ACE-Step v1's end-to-end diffusion
generation), **the two systems fail on almost exactly the same
categories**:

- **`rapid_letter_names` fails completely on both** — this pipeline's
  "Oh, Lucy!" is just as unrelated to the target as any of ACE-Step v1's
  3 seeds. Isolated letter-name articulation appears to be hard
  independent of the generation strategy.
- **`fricative_heavy` and `long_sustained_vowels` are weak on both** —
  ACE-Step v1's own "genuinely unreliable"/"distinct failure mode" tiers
  for these exact categories are echoed here.
- **Ordinary conversational/repeated/final-stop content is reliable on
  both.**

This cross-backbone agreement is a meaningful, if not conclusive, signal
that these specific failure categories may reflect a shared weakness
upstream of either backbone's own mechanism — most plausibly Whisper's
own ASR behavior on this kind of content once rendered with any sung/
quasi-sung pitch contour (rapid isolated letters, alliterative
tongue-twisters, and long melismatic vowels are all known-hard cases for
speech ASR generally, independent of synthesis quality) — rather than
either backbone being specifically bad at these phrase types. This is
not proven here (would need e.g. a real-human-recording control on these
exact phrases through the same Whisper pipeline to fully isolate ASR-vs-
synthesis), but it's the more parsimonious reading of two structurally
unrelated systems failing identically.

## Scope and what NOT to conclude

- **n=1 trial per phrase, not 3 seeds like Gate D.** Kokoro's TTS
  generation is deterministic for fixed text+voice (no exposed seed/
  sampling stochasticity in the basic `pipeline()` call used throughout
  this pipeline) — re-running the identical text would very likely
  reproduce near-identical output, unlike ACE-Step v1's inherently
  stochastic diffusion sampling across seeds. This is itself a real,
  disclosed property difference between the two backbones (consistent
  with "deterministic architecture: pass" from the review), not a
  shortcut taken to save time — but it means seed-to-seed variance
  (Gate A's original finding for ACE-Step v1) has no direct analog to
  test here. Genuine untested sources of variability for this pipeline
  remain: different melody choices, different voice selection, and
  different word/note count mappings.
- The melody was auto-generated by a simple cycling rule, not
  hand-composed per phrase — a different melody (e.g. one requiring
  larger leaps or more extreme registers) is untested here; that's
  Gate 4 (musical stress test) territory, not this gate.
- No human listening check on any of these 10 renders (same standing
  caveat as every other gate in this arc).
