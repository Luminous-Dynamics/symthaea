# Open-Set and Memory-Scaling Stress Benchmark

**Status:** experiment implemented; exact-head validation pending  
**Implementation:** crates/core/symthaea-core/examples/platonic_open_set_memory_stress.rs  
**Runner:** .github/workflows/levin-pattern-experiments.yml

## Research question

Does retrieval quality and selective reliability survive increasing registered-memory size when the memory contains correlated, near-duplicate entries? Can the same rule reject unknown identities, ambiguous composites, and random out-of-distribution queries without making coverage collapse?

This complements the existing 4,096-dimensional, 64-prototype selective-risk benchmark. It is not a replacement for independent risk certification, identity-evidence verification, or a public-dataset SOTA comparison.

## Executable protocol

The runner uses three deterministic seeds (17, 29, 41), fixed 4,096-dimensional bipolar vectors, and total memory budgets of 16, 64, and 256 entries. Each size is tested with two bank conditions:

- **Independent:** all stored entries are independently seeded identities.
- **Correlated shadows:** half the total entries are independent base identities; the remaining half are separately labelled prototypes generated by flipping 2% of a base vector's coordinates. Total stored vector payload remains exactly matched to the independent condition.

For each bank, it evaluates 128 deterministic queries in each stratum: known patterns with 0%, 10%, 20%, and 30% corruption; random OOD patterns; three-prototype bundled mixtures; and unregistered near-prototype queries at 5%, 10%, and 20% corruption. The mixture and unregistered probes have no valid registered identity, so accepting a unique identity counts as an error.

The declared diagnostic acceptance rule is similarity >= 0.25 and top-two margin >= 0.05. It is intentionally held fixed across bank sizes and conditions to expose calibration drift as a controlled factor. **It is not calibrated and it has no finite-sample risk guarantee.** Thresholds must not be tuned on the evaluation output.

The CSV emits each seed and stratum separately: top-1 accuracy for known queries, accepted coverage, accepted-query risk, a Wilson 95% upper endpoint for accepted risk, unknown false-accept rate and its Wilson upper endpoint, mean top similarity and margin, per-query p50/p95 ranking latency, and estimated stored-vector payload bytes. The Wilson bounds are descriptive IID approximations: repeated query corruptions share base identities, so these values are not cluster-robust confidence bounds and do not certify deployment risk. Payload excludes labels, heap allocation overhead, process RSS, indexes and allocator capacity. Latency here is exact linear scan over the Rust prototype bank, not a comparison to an ANN index. Run-time figures from the synthetic stress test must not be compared directly with database benchmarks without matched hardware, formats, warm-up, query workload and measurement rules.

## Falsifiable targets for the next tranche

These are **targets, not achieved results**:

1. At each declared noise level and byte budget, report K95: the largest tested memory size whose lower 95% confidence bound on held-out recall remains at least 95%. Keep this fail-closed across the tested grid; report later non-monotone points but do not let them requalify.
2. At the declared synthetic distribution, target a one-sided upper 95% risk bound below 5% while preserving at least 70% coverage. Require independent calibration/certification/evaluation streams and family-wise error control for policy/seed comparisons.
3. On the correlated-shadow and near-unknown strata, report false accepts separately from ordinary top-1 classification mistakes. A pooled score may never hide open-set failure.
4. Expand the final estimate to at least five independent seeds and at least 1,000 queries per reported operating point; calculate confidence intervals at the appropriate unit of independence and disclose repeated queries per prototype.
5. Compare HDC/MAP, HRR and other faithfully implemented VSA algebras at equal vector dimension **and** equal stored bytes. Include a conventional linear classifier such as SVM/RVFL on compatible public tasks; don't infer superiority from synthetic prototype retrieval alone.
6. On public vector retrieval workloads, compare an exact-scan oracle with ANN index baselines using exact-ground-truth Recall@K, p50/p95 latency, QPS, index/build time and measured peak memory. Keep task accuracy/risk separate from neighbor-retrieval fidelity.

## Paradigm shift

Treat the memory as an open-world evidence system rather than a closed-set lookup table. Similarity produces candidates; calibrated risk decides whether to answer; ambiguous mixtures can produce a set or trigger additional evidence collection; and semantic identity requires an independent enrollment capability. A more confident nearest neighbour is not evidence that a query belongs to the registry.

The next algorithmic experiment should test an explicit action policy: answer, return a candidate set, request another independent view, or abstain. Measure its utility under a fixed sensing/compute budget. The current executable is a stress diagnostic for the memory-size and distractor axes; it does not implement that active evidence-acquisition policy.

## Comparison sources

- Vergés et al. (2025), *Classification using hyperdimensional computing: a review with comparative analysis*, proposes common evaluation across seven established HDC datasets and 121 UCI tasks. https://doi.org/10.1007/s10462-025-11181-2
- Gangrade, Kag, and Saligrama (2021), *Selective Classification via One-Sided Prediction*, provides a class-wise risk/coverage comparator. https://proceedings.mlr.press/v130/gangrade21a.html
- Dong, Hao, and Shinnou (2026), *Fixed-Sequence Confidence-Interval Calibration for Finite-Sample Selective Risk Control*, is a recent predeclared-threshold baseline; the existing fixed-sequence code remains a scoped adaptation and should be checked against the paper. https://doi.org/10.3390/stats9050109
- Yu and Liu (2026), *A Joint Finite-Sample Certificate for Adaptive Selective Conformal Risk Control*, studies joint risk/acceptance/utility guarantees under adaptive selection, with empirical results on specific domains that do not imply transfer to HDC. https://arxiv.org/abs/2606.08517
- ANN-Benchmarks documents reproducible ANN comparison and ground-truth, single-query versus batched-workload, and resource-measurement considerations. https://github.com/erikbern/ann-benchmarks
