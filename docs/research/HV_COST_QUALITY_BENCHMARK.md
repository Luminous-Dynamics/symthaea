# HDC cost-quality benchmark

Research-only benchmark contract. Compare representations at matched task quality.

## Dimensions

- retrieval quality and rank preservation
- bind/unbind cost
- bundle cost
- sequence encoding
- resident bytes
- materialization bytes
- bytes moved
- allocations
- latency and cycles where available
- cache behavior
- energy only when directly measured

Unknown measurements remain unknown, never zero. Report Pareto frontiers, not a universal winner.
