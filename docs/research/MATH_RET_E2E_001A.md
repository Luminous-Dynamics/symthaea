# MATH-RET-E2E-001A — Guarded S Exact-Ranking Evidence Capsule

Status: draft mechanical interoperability qualification.

## Purpose

Exercise the complete qualified-retrieval evidence chain around **one synthetic S-arm event** before the real canonical-AST encoder is connected.

This tranche introduces no new scientific representation or retrieval contract. It composes the contracts already frozen by the preceding lineages.

## Why a synthetic representation is intentional

The real structural representations remain isolated in the #4087 → #4112 lineage and are not yet safe to copy into the guarded runtime stack.

This capsule therefore uses a representation explicitly identified as:

```text
SyntheticCanonicalSparseForMechanicalQualificationOnly
```

Its only purpose is to make the existing guarded Rust ranking independently reproducible from exact bytes.

A PASS is **not evidence about canonical-AST retrieval quality**.

## Frozen positive geometry

The guarded S runtime already returns:

```text
[a1, a2, a3]
```

The capsule materializes canonical sparse wires such that exact cosine order is:

```text
query = {a:1, b:1}

a1 = {a:2, b:2}  -> highest
a2 = {a:3, b:1}  -> second
a3 = {a:3}        -> third
all remaining candidates have zero query overlap
```

No runtime ranking is changed to fit the geometry. Instead the fixture geometry is preregistered to test whether the independent replay machinery reconstructs the already-frozen runtime sequence.

## Pre-graph construction

Before graph qualification the driver precomputes:

1. the exact 32-source candidate artifact;
2. one canonical sparse wire object per candidate;
3. the transparent exact S index artifact;
4. executable scoring / precision / query-normalization component digests.

Only four existing S graph labels are overridden before graph construction:

```text
runtime-001b-score-S
runtime-001b-precision-S
runtime-001b-query-S
runtime-001b-index-artifact-S
```

All other graph identities are generated by the existing builder. Binding, experiment and bundle identities therefore cascade normally from the real object bytes rather than being patched after qualification.

## Authority boundary

A PASS establishes **mechanical interoperability of the complete guarded retrieval evidence path** for the synthetic fixture.

- that #4087 or #4112 have qualified;
- canonical-AST retrieval benefit;
- HDC benefit;
- fusion benefit;
- semantic equivalence;
- proof success;
- theorem truth;
- novelty.

Authority remains `MeasurementOnly`.

2. prove bit-for-bit compatibility with their predecessor harnesses;

4. require the same candidate/build/query/runtime/replay chain;
