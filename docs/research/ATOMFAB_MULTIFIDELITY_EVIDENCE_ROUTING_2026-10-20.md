# AtomFab multi-fidelity evidence routing v1

**Status:** Executable decision-policy primitive; synthetic fixtures only. No materials performance result is claimed.

## Paradigm shift: choose the next evidence action, not only the next structure

A discovery system spends resources on different questions. A cheap static screen, universal ML interatomic potential, domain-specific potential, DFT calculation, process-twin simulation and calibrated measurement have different costs and answer different questions. An MLIP cannot validate a tool path; a rigid-body workcell simulation cannot establish surface chemistry; a simulation-generated value cannot become a measurement.

The new Rust `evidence_router` ranks evidence actions *within one decision request and one evidence domain* by calibrated expected decision-loss reduction per fixed-resolution cost unit. It uses integer cross-products to compare ratios exactly, with deterministic ties; it does not use floating-point division. An action is ineligible if prerequisites are missing, the model is outside its declared domain, the value estimate is not calibrated, the action type does not match the evidence domain, there is zero declared expected loss reduction, or cost exceeds the budget. All rejected/blocked actions remain in the report with reasons; if nothing is eligible, the router abstains (`selected_action_id = null`).

The value estimate is not generated by the router. It must be calibrated and supported by a traceable evidence digest; that estimate itself needs an out-of-sample calibration protocol before a real campaign can rely on it. Integer unit names and contract digests must encode compatible resolutions and semantics.

## Why now?

The 2026 supported Cu/Al2O3 nanoparticle benchmark explicitly shows that energy error and search performance can diverge across universal ML interatomic potentials, while the domain-specific DP-UniAlCu model was substantially faster in the reported MD comparison. This favors choosing the fidelity/model for the actual next decision rather than assuming the biggest or most accurate model is always the economically best next action. [Xu et al., npj Computational Materials (2026)](https://doi.org/10.1038/s41524-026-02043-8).

A 2025 *Scientific Reports* benchmark of 17 active-learning strategies across nine materials datasets found that uncertainty-driven and diversity-hybrid strategies performed better early, but strategy differences narrowed as the labelled set grew. This is a warning against permanently hard-coding one acquisition heuristic: the router needs to be evaluated at different data budgets and learning stages. [Bi et al. (2025)](https://doi.org/10.1038/s41598-025-24613-4).

For model validity, material-family and support-surface holdouts matter: a nominally independent random split can still occupy regions covered by training data and overstate true out-of-distribution behavior. [OOD generalization study](https://doi.org/10.1038/s43246-024-00731-w).

## Baselines and metrics

Compare:
- Fixed cheapest-first escalation.
- Random selection among currently eligible actions.
- Uncertainty-only escalation.
- Cost-aware acquisition / expected information gain where the value estimate is calibrated.
- Symthaea router.
- Router with evidence history/retrieval ablated.

Report target attainment, best reference-validated objective at equal cost, unique validated discoveries, total cost including failed queries/rework, time-to-target, fidelity/action mix, calibration of estimated decision value, selected-action regret against retrospective oracle decisions, abstention frequency and OOD rejection. Use Pareto reporting for discovery count/objective/cost. Report every fixed seed, including failed or incomplete campaigns.

No cross-domain score should combine atomistic and process-twin actions. Run separate decisions with the same objective contract in each domain, then join them at the manufacturing-intent level where both evidence branches are required.
