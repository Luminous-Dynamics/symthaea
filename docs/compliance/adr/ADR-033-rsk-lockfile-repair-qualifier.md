# ADR-033: RSK lockfile repair qualification

**Status**: Accepted

**Change Class**: A

**Scope**: Replicator Safety Kernel qualification only

## Decision

RSK `Cargo.lock` repair candidates MUST be generated by pinned Cargo on an exact-head ephemeral executor and MUST NOT be treated as admissible evidence merely because Cargo produced them.

A candidate is eligible for human review only when an independent structural delta qualifier proves:

1. Cargo.lock format remains version 4;
2. all pre-existing non-RSK package records are exactly unchanged;
3. each RSK workspace package appears exactly once as a path package with no registry source/checksum;
4. RSK package versions remain `0.1.0`;
5. dependency edges are exactly:
   - `symthaea-replicator-semantics` -> none;
   - `symthaea-replicator-safety` -> `symthaea-replicator-semantics`, `sha2`, `serde_json`, `hex`;
   - `symthaea-replicator-ledger` -> `symthaea-replicator-safety`;
6. no unrelated package addition, removal, version/source/checksum change, or dependency-edge change is accepted.

The diagnostic workflow MUST preserve the original committed lockfile, the Cargo-generated candidate, the textual diff, SHA-256 identities, exact source head, and pinned toolchain identity as review artifacts.

## Evidence boundary

The generated artifact is **NON-ADMISSIBLE DIAGNOSTIC EVIDENCE**. It MUST NOT be automatically committed, merged, or substituted into an RSK qualification receipt.

A later Class A change must commit the reviewed Cargo-generated `Cargo.lock`, after which normal focused RSK qualification must succeed with `--locked` and bind the exact committed lockfile digest.

## Rationale

The workspace lock is currently missing the RSK path-package records tracked by #1926. Hand-authoring those records or weakening `--locked` would undermine reproducibility. Conversely, accepting arbitrary Cargo refresh output could silently introduce unrelated dependency drift. The separate generator/qualifier split preserves both constraints.

## Non-claims

This ADR does not establish that the RSK Rust crates compile, that the candidate lockfile has been accepted, or that production admission is eligible. Production admission remains **DENIED / NOT YET ELIGIBLE**.
