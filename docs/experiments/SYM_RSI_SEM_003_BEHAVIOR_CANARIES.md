- `BinaryHV` width: 16,384 bits / 2,048 bytes;
- deterministic `BinaryHV::random(seed)` as BLAKE3 XOF over `seed.to_le_bytes()`;
- role binding by XOR;
- deterministic level encoding with 64 levels and clamp `[-1, 1]`;
- role and length seeds generated by the frozen `mix64` construction;
- context bundling by per-bit majority vote;
- Hamming similarity as matching bits divided by 16,384.

The independent BLAKE3/XOF implementation was checked against the official BLAKE3 extended-output vectors for both empty input and an 8-byte input. The 8-byte case is important because `BinaryHV::random(seed)` hashes exactly eight seed bytes.
