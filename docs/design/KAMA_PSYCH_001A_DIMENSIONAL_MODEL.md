# KAMA-PSYCH-001A — Dimensional Intimacy Psychology Evidence

Status: source-design candidate
Parent issue: #4782
Authority: descriptive psychological evidence only; **no consent or physical authority**

## Purpose

Represent adult intimacy psychology as multidimensional, context-scoped, uncertainty-bearing evidence rather than fixed sexual personality types.

## Scientific boundary

The model may represent constructs informed by published research, including excitation/inhibition propensities and desire-related dimensions, but does not diagnose a person or infer a validated psychometric score from ordinary conversation.

Validated questionnaires are optional self-report evidence sources only when separately administered/authorized. Their factor structure, population validity, and cultural applicability remain instrument-specific.

## V1 dimensions

- sexual excitation propensity;
- sexual inhibition propensity;
- dyadic desire;
- solitary desire;
- emotional closeness need;
- reassurance need;
- independence need;
- novelty preference;
- familiarity preference;
- communication directness.

This vocabulary is intentionally incomplete and extensible. It is not a universal taxonomy.

## Required separations

## Evidence sources

V1 keeps separate:

1. population prior;
2. physiological inference;
3. behavioral inference;
4. repeated explicit feedback;
5. validated self-report instrument;
6. explicit user statement.

Higher-ranked evidence may be selected for a matching dimension/context, but rank is not truth and does not convert one semantic category into another.

Physiological inference is restricted to `CurrentState` and cannot establish a trait-like property.

## Context and currentness

Every item binds temporal scope, reality scope, context identity, observation time, optional validity deadline, source reference, confidence, and retention class.

Expired current-state evidence is not reused. Fantasy-only evidence cannot answer a real-world query. One relationship/session/story context cannot silently answer another.

## Unknown is first-class

If no applicable current evidence exists, the model returns no estimate rather than manufacturing one from demographics or population stereotypes.

## Privacy

V1 distinguishes ephemeral-session evidence from durable opt-in evidence. It does not implement persistence by itself.

## Nonclaims

This tranche establishes no clinical diagnosis, universal psychometric validity, sexual preference prediction, fantasy-session activation, content permission, human-contact consent, motor authority, or medical authority.
