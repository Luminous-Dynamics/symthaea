# Scientific Method Kernel Audit v1 — Review Checklist

This checklist reviews `SCIENTIFIC_METHOD_KERNEL_AUDIT_V1.md` only. It does not qualify any scientific claim or production implementation.

## Semantic separation

- [ ] Artifact identity is not treated as verified content.
- [ ] Verified content is not treated as trusted source evidence.
- [ ] Observation and interpretation remain distinct.
- [ ] Hypothesis and publication-grade claim remain distinct.
- [ ] Exploratory and confirmatory evidence remain distinct.
- [ ] Numerical, bounded, SMT-sample, symbolic, and formal verification remain distinct.
- [ ] Uncertainty/calibration is not collapsed into epistemic authority.
- [ ] Causal structure is not collapsed into causal identification.
- [ ] Scientific evidence is not allowed to mint safety/effect/action/self-improvement authority.
- [ ] Replication is not inferred from paper/model/author/institution count.
- [ ] No global scalar confidence/evidence score is required.

## Generalization safety

- [ ] Proposed common types are narrower than or equal to all migrated domain semantics.
- [ ] No domain qualification is inherited by a future common abstraction.
- [ ] Domain-specific assumptions such as conformal exchangeability remain domain-owned.
- [ ] Neuro execution-capsule semantics are not weakened by the generic proposal.
- [ ] Physical Agency preregistration does not accidentally transfer actuator/safety authority.
- [ ] Economics causal/measurement semantics are preserved as typed dimensions.
- [ ] Futures timing/custody distinctions survive any generic provenance design.
- [ ] RCA evidence-lineage/disposition separation remains intact.

## Discovery hardening

- [ ] Conjecture status reporting must become exhaustive before kernel migration.
- [ ] Rich uncertainty-bearing observations are additive to, not a silent reinterpretation of, `(x, y)` observations.
- [ ] Prediction-disagreement variance remains a baseline after richer experiment planning is added.
- [ ] Learned grammar/macros are treated as evidence dependencies.
- [ ] Discovery backends are evaluated against common frozen observations rather than granting backend-specific authority.

## Causal hardening

- [ ] Existing causal graph representations are inventoried before unification.
- [ ] DAG APIs fail closed on cycle creation unless a cyclic model is explicitly selected.
- [ ] Text/knowledge-derived causal edges retain provenance and uncertainty.
- [ ] Genesis perturbations are treated as interventions only under explicit experiment/causal contracts.

## Benchmark honesty

- [ ] Historical discovery benchmarks freeze source availability before `t0`.
- [ ] Model/tool/embedding/grammar provenance is checked for post-cutoff knowledge leakage.
- [ ] Novelty conclusions are scoped to explicit search receipts.
- [ ] Null, negative, contradicted, refuted, inconclusive, and indeterminate results remain reportable evidence.

## Implementation ordering

- [ ] SCI-002 waits for qualified neutral digest computation and bytes-to-digest verification.
- [ ] SCI-003 waits for the NeuroBridge execution-capsule lineage to qualify sufficiently to generalize without weakening it.
- [ ] SCI-004 is non-result-bearing preregistration infrastructure.
- [ ] SCI-005 prevents exploratory results from directly minting confirmatory evidence.
- [ ] SCI-006 emits dependency topology, not `independent: bool`.
- [ ] SCI-007 introduces falsifiers/evidence relations without a universal score.
- [ ] SCI-008 preserves the legacy observation path as an explicit adapter.
- [ ] SCI-009 exposes decision dimensions/Pareto structure rather than requiring one scalar utility.
- [ ] SCI-010 keeps symbolic-discovery backends comparable under one adjudication contract.
- [ ] SCI-011 binds learned discovery primitives to originating evidence lineage.
- [ ] SCI-012 uses Genesis as the first complete controlled intervention loop.
