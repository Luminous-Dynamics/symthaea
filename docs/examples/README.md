## Running Examples

### Basic (no features)
```bash
cargo run --example phi_engine_quick_demo
```

### With Features
```bash
cargo run --example phi_dyad_demo --features partnership_module
cargo run --example conscious_ollama_demo --features language_module
cargo run --example clinical_validation  # No features needed
```

### With Release Optimizations
```bash
cargo run --release --example hdc_simd_benchmark
```
