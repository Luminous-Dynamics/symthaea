## Pre-Filing Qualification

### Micro Entity Status (37 CFR 1.29)
- [ ] Fewer than 4 previously filed patent applications (US or international)
- [ ] Gross income under $234,788 (3× median household income, 2026)
- [ ] Not obligated to assign to entity with >$234,788 income
- [ ] Not named on more than 4 previously filed applications
- **Filing fee with micro entity**: $320 (vs $1,600 small entity, $3,200 large entity)

### Required for Each Application
- [ ] Micro Entity Certification (Form PTO/SB/15A)
- [ ] Provisional Application Cover Sheet (Form PTO/SB/16)
- [ ] Specification (the IDD, reformatted)
- [ ] Drawing(s) if applicable (text descriptions → actual figures)
- [ ] Filing fee payment ($320 per provisional)

## Key Legal Reminders

- **Provisional → Utility**: Must file within 12 months or lose priority date
- **International**: File PCT within 12 months of provisional for international protection
- **Continuation**: Can file continuation applications claiming priority to provisional
- **No examination**: Provisionals are NOT examined — they only establish priority date
- **Disclosure**: Must include sufficient detail to support later utility claims
