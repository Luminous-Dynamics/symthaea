## 💚 The Dynamic Regenerative Exit Model

### Core Principle: Conditions-Based, Not Time-Based
The transition to community ownership is triggered by **achieved milestones**, not arbitrary timelines. This ensures readiness, sustainability, and success for all parties.

#### Phase 1: Investment & Returns (Typically Years 0-7)
**Exit Conditions** (must meet ALL):
- ✓ Investors achieve target IRR (11-14%)
- ✓ Project reaches operational stability
- ✓ Initial capital recovered + agreed returns
- ✓ Community engagement framework established

#### Phase 2: Shared Prosperity (Variable Duration)
**Transition Triggers**:
- Community readiness score > 75%
- Local management capacity verified
- Financial sustainability demonstrated
- Regulatory framework in place

const RegenerativeExitProtocol = {
  // Dynamic ownership calculation
  calculateOwnershipTransfer: (project) => {

### Why Dynamic > Fixed Timeline

**Protects Communities**:
- No premature handover before capacity exists
- Ensures financial sustainability
- Builds management expertise gradually

**Benefits Investors**:
- Faster exit if conditions are favorable
- Extended returns if more time needed
- Reduced risk through verified handover

**Optimizes Outcomes**:
- Responds to local conditions
- Rewards high performance
- Adapts to challenges
