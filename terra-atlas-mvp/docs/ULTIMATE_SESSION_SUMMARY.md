## 🎓 Lessons Learned

### Technical Lessons
1. **Shaders > Materials**: Custom GLSL enables impossible effects
2. **Layers = Depth**: Multi-layer glows create dimension
3. **Organic Timing**: Random offsets = life
4. **Additive Blending**: Perfect for energy/glow effects
5. **GPU Acceleration**: Shaders keep 60 FPS despite complexity

### Design Lessons
1. **Subtle > Flashy**: 40% opacity particles more premium than 100%
2. **Slow > Fast**: 21s particle rise more majestic than 5s
3. **Selective > Universal**: Particles only on large sites = hierarchy
4. **Harmonious > Random**: Color coordination creates beauty
5. **Meaningful > Pretty**: Every element serves the story

### Process Lessons
1. **Cache Management**: Must automate to prevent frustration
2. **Incremental Enhancement**: Build layer by layer
3. **Documentation**: Write as you build, not after
4. **Verification**: Test constantly during development
5. **Vision Clarity**: "Best we can" clear north star
