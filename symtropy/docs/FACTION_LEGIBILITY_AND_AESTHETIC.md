# Faction Legibility and Aesthetic Grammar

## Purpose

Procedural factions will fail if players cannot read them quickly.

Symtropy may generate dozens of archetypes and hybrid societies, but every faction must still be understandable at a glance.

A player should not need to read a lore document to understand the basic identity of a group they encounter.

They should be able to tell from architecture, vehicles, clothing, signage, behavior, lighting, sound, and settlement layout.

## Core Principle

**Procedural complexity must produce readable forms.**

Each generated faction should have:

* one primary archetype
* one secondary archetype
* one sacred value
* one taboo
* one crisis scar
* one failure mode
* one visual motif
* one behavioral motif
* one preferred mission type

This keeps factions deep without making them illegible.

## Procedural Aesthetic Matrix

Every archetype should define a visual grammar kit.

A visual grammar kit contains:

* silhouette language
* material palette
* lighting style
* structure shapes
* signage style
* clothing motifs
* armor motifs
* vehicle modifications
* UI motifs
* sound motifs
* settlement layout
* NPC behavior tells
* public ritual tells

Hybrid factions blend these kits.

The blend should not be random.

The primary archetype controls structure and layout.

The secondary archetype modifies details, signage, clothing, vehicles, and public rituals.

## Hybrid Example: Salvage Clan + Archive Order

Generated faction:

```text
Rustwake Memory Caravan
```

Readable form:

* mobile archive trucks
* welded data-spires
* blue archive lanterns on scrap frames
* shipping containers converted into memory vaults
* scavengers who scan ruins before stripping parts
* road shrines made from black boxes
* NPCs carrying record canisters
* rituals before dismantling wrecks

Sacred value:

```text
Witness before salvage.
```

Taboo:

```text
Stripping ruins before recording them.
```

Preferred missions:

* recover black boxes
* scan dead settlements
* escort archive caravans
* protect evidence from raiders
* decide whether a ruin may be dismantled

Failure mode:

```text
They begin selling selective truth to the highest bidder.
```

This faction is complex, but readable.

## Hybrid Rules

### Primary Archetype Controls

* settlement layout
* main buildings
* economy
* governance spaces
* dominant silhouette

### Secondary Archetype Controls

* decorative motifs
* mission flavor
* clothing details
* vehicle modifications
* signage
* public rituals
* failure mode accent

### Crisis Scar Controls

* damage pattern
* memorials
* fear behavior
* taboos
* security changes
* NPC trauma cues

Example:

```text
Primary: Mutualist Assembly
Secondary: Security Protectorate
Crisis Scar: Convoy Massacre
```

Output:

* still has open commons and public wells
* adds watchtowers and road checkpoints
* memorial wall for lost convoy
* children avoid gates
* public vote debates patrol expansion
* militia recruitment posters appear
* NPCs argue about whether the settlement is still free

## UI Legibility

Every faction UI card should show:

```text
Primary Archetype
Secondary Archetype
Sacred Value
Taboo
Current Pressure
Coherence
Legitimacy Debt
Timeline Stance
Failure Risk
```

Example:

```text
Rustwake Memory Caravan
Primary: Salvage Clan
Secondary: Archive Order
Sacred Value: Witness before salvage
Taboo: Stripping unrecorded ruins
Pressure: Fuel scarcity
Coherence: High
Legitimacy Debt: Low
Timeline Stance: Preserve before fork
Failure Risk: Selective truth trade
```

## Audio Grammar

Audio should support faction readability.

Examples:

* Mutualist Assembly: tools, voices, public bells, warm workshop ambience
* Industrial Compact: machinery rhythm, shift sirens, rail, compressors
* Null Ecology: signal pulses, servo swarms, distorted machinery, low red hum
* Archive Order: soft data chimes, archival drones, quiet rooms, layered whispers
* Salvage Clan: welding, engines, rattling metal, radio chatter
* Security Protectorate: boots, drones, public orders, gate alarms
* Terraforming Covenant: water, insects, wind, grow lights, soft rituals
* Reactor Order: deep hum, coolant flow, warning tones, grid pulses

## Behavioral Grammar

NPCs should make archetypes visible through action.

Examples:

* Mutualists repair public tools without being asked.
* Industrial workers check production boards.
* Salvagers strip parts from abandoned objects.
* Archivists scan and tag ruins.
* Security actors patrol and question strangers.
* Terraformers test soil and water.
* Convoy workers maintain vehicles.
* Reactor orders inspect power systems.
* Machine stewards greet robots by name.
* Null drones ignore beauty and optimize routes.

## Final Principle

A generated faction is successful when a player can say:

```text
I do not know their full history yet, but I understand what kind of society they are.
```

Procedural depth must become visible culture.
