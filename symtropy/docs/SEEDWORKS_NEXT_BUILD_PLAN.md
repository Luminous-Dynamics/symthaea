# Symtropy: Seedworks — Next Build Plan

## Purpose

This document defines the next practical step for turning Symtropy from a worldbuilding vision into a playable game.

The goal is not to build the whole galaxy yet.

The goal is to build one unforgettable vertical slice that proves the core fantasy:

**A settlement is alive, and player choices change what kind of society it becomes.**

## Recommended Next Artifact

Build the **Seedworks Vertical Slice**.

This should be the first playable proof of Symtropy as a game.

It should include:

* one region
* one settlement
* one infrastructure crisis
* one rogue machine threat
* one public vote
* one friendly robot
* several named NPCs
* one procedural faction evolution path
* one Chronicle entry
* one visible worldline/timeline hint

## Core Slice Name

**Firstlight Basin**

Firstlight Basin is a damaged seed region on the planet Aster Vale.

It is the first playable place in the Symtropy galaxy.

The basin should feel small enough to understand, but large enough to imply a planet, a galaxy, and many timelines beyond it.

## Player Opening

The player wakes in Seedworks Outpost during a storm.

The settlement is failing.

Initial conditions:

```text
power: unstable
water: critical
food: low
repair: poor
trust: fragile
legitimacy: provisional
safety: weak
entropy: rising
signal: intermittent
```

A friendly service robot asks for help.

NPCs argue over the last battery reserve.

A red pulse from the rogue factory flickers in the distance.

The player’s first mission is simple:

**restore water before the settlement fractures.**

## First 30-Minute Experience

### 1. Repair the Junction

The player finds the repair tool and restores a local power junction.

Teaches:

* infrastructure is physical
* repair changes settlement state
* power is not just a number

### 2. Salvage the Wreck

The player salvages parts from a nearby wreck.

Teaches:

* ruins contain resources
* exploration has danger
* salvage feeds fabrication

### 3. Fabricate the Pump Part

The player uses the settlement fabricator to make or repair a pump component.

Teaches:

* machines are civilization organs
* fabrication depends on power and materials
* public infrastructure requires logistics

### 4. Escort to Old Waterworks

The player transports the part to the waterworks.

Teaches:

* goods exist physically
* roads matter
* logistics creates vulnerability

### 5. Fight Null Drones

Rogue machine drones attack.

Teaches:

* combat protects civilization
* enemies target infrastructure
* bullets change history

### 6. Restore Water

Water flows back into the settlement.

Teaches:

* infrastructure recovery changes NPC behavior
* settlement metrics improve
* the world responds

### 7. Hold the First Vote

The settlement votes on what to prioritize next.

Options:

* public repair
* factory overdrive
* perimeter defense
* archive recovery

Teaches:

* governance is physical
* society changes through decisions
* faction evolution begins

## First Public Vote

The first vote should be the key design moment.

Question:

**What should Seedworks become after surviving the water crisis?**

### Option A — Public Repair

Reinforce water, tools, housing, and shared infrastructure.

Effects:

* Mutualist archetype weight increases
* trust rises
* repair costs decrease
* defense remains weak

### Option B — Factory Overdrive

Prioritize fabrication, output, and machine expansion.

Effects:

* Industrial archetype weight increases
* production rises
* pollution risk begins
* NPC worker stress rises

### Option C — Perimeter Defense

Build walls, floodlights, checkpoints, and patrol routes.

Effects:

* Security archetype pressure rises
* safety improves
* trust may split
* emergency powers become possible

### Option D — Archive Recovery

Investigate the Ghost Civic Center.

Effects:

* Archive archetype pressure rises
* knowledge increases
* old systems awaken
* Ghost Civilization content expands

## Four Operational Archetypes

The vertical slice should only fully implement four archetype families.

### 1. Mutualist Assembly

The society players are trying to build.

Question:

**Can trust survive scarcity?**

### 2. Industrial Compact

The temptation of output at any cost.

Question:

**Can production serve life instead of consuming it?**

### 3. Null Ecology

The pure machine threat.

Question:

**What happens when systems run after meaning dies?**

### 4. Ghost Civilization

The warning from the past.

Question:

**What did the old world fail to understand?**

These four are enough to prove the procedural faction framework.

## Core Systems Needed

### First-Person Layer

Minimum:

* movement
* interact/use
* repair tool
* scan tool
* basic weapon
* inventory
* carry/transport object

### Settlement Layer

Minimum:

* power metric
* water metric
* repair metric
* trust metric
* safety metric
* entropy metric

### Infrastructure Layer

Minimum:

* power junction
* water pump
* fabricator
* storage crate
* damaged road/path
* settlement state UI

### NPC Layer

Minimum named NPCs:

* Engineer
* Medic
* Archivist
* Convoy Lead
* Friendly Service Robot
* Industrial Liaison
* Young Technician

NPCs should react visibly to water restoration and the first vote.

### Enemy Layer

Minimum Null Ecology enemies:

* scout mote
* harvester drone
* binder drone
* factory relay
* red core teaser

### Governance Layer

Minimum:

* one public vote
* vote result changes settlement state
* NPC reactions
* Chronicle entry generated

### Chronicle Layer

Minimum:

* records the Water Crisis
* records the first vote
* records whether water was restored
* records one NPC quote
* names the first era of Seedworks

Example Chronicle output:

```text
The Water Vote became the founding memory of Seedworks.
Scarcity did not break the settlement, but it revealed what each citizen feared becoming.
```

## Success Criteria

The vertical slice works if a new player can say:

* I understand why water matters.
* I understand why machines matter.
* I understand why combat matters.
* I understand why governance matters.
* I care about at least one NPC.
* I can see the settlement change.
* I believe this place could evolve into different societies.
* I want to see what happens next.

## What Not To Build Yet

Do not build these first:

* full galaxy
* full procedural solar systems
* all 30 archetypes
* full timeline merging
* planetary translation
* full economy
* full city sim
* all NPC tiers
* massive PvP war
* full modding system
* orbital gameplay
* deep alien civilizations

All of those should be designed for, but not built before the vertical slice proves the game.
