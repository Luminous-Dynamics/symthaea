# Procedural Faction Evolution

## Purpose

Symtropy should not use fixed named factions as the permanent political structure of the galaxy.

Instead, factions should emerge from procedural archetypes, local conditions, history, scarcity, trauma, technology, governance, and worldline philosophy.

A faction is not a brand.

A faction is a society under pressure.

## Core Principle

**Thresholds create pressure. Emergency systems react. NPCs interpret the crisis. Civic systems decide legitimacy. Repeated choices shift archetype weights. The Chronicle records what the society becomes.**

Faction evolution should never be a simple if-statement such as:

```text
if water < 20%:
    become Security Protectorate
```

That would feel artificial.

Instead, the water crisis should create pressure. The society’s response to that pressure determines its future.

## Two Kinds of Faction State

Faction behavior should be divided into two layers.

## 1. Operational Posture

Operational posture is fast, reversible, and mostly automatic.

Examples:

* rationing mode
* lockdown mode
* evacuation mode
* convoy emergency
* flood response
* martial patrols
* quarantine perimeter
* factory overdrive
* public works surge
* archive preservation mode

Operational posture can be triggered by hard thresholds.

Example:

Water infrastructure drops below 20%.

The settlement automatically enters water emergency mode:

* rationing begins
* water missions appear
* public stress rises
* NPCs change schedules
* guards move to wells
* black-market risk rises
* public trust begins to decay
* civic proposals are generated

No vote is needed for the immediate survival response.

## 2. Civilizational Identity

Civilizational identity is slow, sticky, political, and historically meaningful.

Examples:

* Mutualist Assembly becomes Security Protectorate
* Industrial Compact becomes Debt Empire
* Research Conclave becomes Quarantine Authority
* Salvage Clan becomes Archive Order
* Convoy Union becomes Freeport League
* Machine Stewardship becomes Synthetic Republic
* Terraforming Covenant becomes Planet-Kin Culture

Identity change should require interpretation, memory, legitimacy, repeated behavior, and defining events.

A society should not become something new because one threshold was crossed.

It becomes something new because of how it repeatedly chooses to survive.

## Evolution Pipeline

Faction evolution should follow this pipeline:

```text
Crisis Event
  ↓
Pressure Vector Changes
  ↓
Emergency Posture Activates
  ↓
NPCs Generate Interpretations
  ↓
Civic Proposals / Splinters / Coup Risks Appear
  ↓
Players Intervene
  ↓
Vote, Reform, Collapse, Schism, Coup, Exodus, or Fork
  ↓
Archetype Weights Shift
  ↓
Chronicle Records the New Identity
```

This lets the same crisis produce different histories.

A water crisis could lead to:

* renewed mutual aid
* public rationing
* water privatization
* military seizure of wells
* ecological reform
* refugee flight
* machine infection
* faction schism
* worldline fork

## Archetype Vectors

Factions should not be locked to one class.

Every faction should have an archetype vector.

Example:

```text
Mutualist Assembly:     0.62
Industrial Compact:     0.13
Security Protectorate:  0.10
Archive Order:          0.07
Convoy Union:           0.05
Raider Swarm:           0.03
```

After repeated raids:

```text
Mutualist Assembly:     0.39
Security Protectorate:  0.41
Industrial Compact:     0.08
Archive Order:          0.05
Convoy Union:           0.04
Raider Swarm:           0.03
```

At this point the game should not simply rename the faction.

Instead, it should surface tension:

```text
The Assembly is no longer sure whether it is a commons or a fortress.
```

This tension creates:

* public arguments
* NPC testimony
* militia recruitment
* emergency proposals
* protest events
* new guard posts
* changed aesthetics
* faction splinter risks
* Chronicle entries

Only after the new archetype remains dominant, wins legitimacy, or seizes control should the faction identity change.

## Pressure Vector

Each faction should track pressure across multiple dimensions.

Example:

```text
water_scarcity:        0.82
raid_threat:           0.61
pollution:             0.24
trust_collapse:        0.48
economic_dependency:   0.32
timeline_instability:  0.13
machine_infection:     0.19
refugee_strain:        0.40
```

Pressure does not decide identity alone.

Pressure generates possible futures.

## Trigger Types

Faction evolution should use four trigger categories.

## 1. Material Triggers

Hard conditions in the world.

Examples:

* water below threshold
* food deficit for many days
* power grid collapse
* pollution above threshold
* convoy loss rate too high
* Null infection spreading
* housing shortage
* reactor instability
* trade route isolation
* tool scarcity
* medical overload

Material triggers activate emergency posture.

## 2. Social Triggers

Trust, legitimacy, and relationship conditions.

Examples:

* public trust collapse
* NPC strike
* militia formation
* corruption evidence
* faction leader betrayal
* failed vote
* refugee tension
* class conflict
* machine-rights dispute
* religious schism
* anti-player resentment

Social triggers create ideological conflict.

## 3. Historical Triggers

Repeated patterns over time.

Examples:

* repeated public works success
* repeated private hoarding
* repeated convoy massacres
* repeated pollution recovery
* repeated use of emergency power
* repeated rescue success
* repeated failed defenses
* repeated archive preservation
* repeated timeline contamination

Historical triggers create archetype drift.

## 4. Symbolic Triggers

Mythic or emotionally defining events.

Examples:

* the first water vote
* death of a founder NPC
* first Confluence signal
* discovery of a ghost city
* first robot elected to office
* first child rescued from a convoy attack
* successful planetary translation test
* betrayal by an allied settlement
* destruction of a sacred archive
* liberation of a rogue factory

Symbolic triggers create identity leaps.

Factions should feel like societies, not spreadsheets.

## FEP, Symthaea, Civic, and Chronicle Layers

Faction evolution should be distributed across four layers.

## FEP Layer — Immediate Survival

The FEP layer handles fast, practical behavior.

It asks:

```text
What reduces immediate uncertainty, threat, or survival error?
```

It controls:

* threat response
* resource seeking
* pollution avoidance
* route changes
* territory defense
* evacuation
* basic aggression
* repair priority
* machine swarm behavior
* energy conservation

## Symthaea Layer — Meaning and Moral Interpretation

The Symthaea layer handles interpretation.

It asks:

```text
What does this event mean to us?
```

It controls:

* sacred values
* taboos
* identity
* grief
* trust
* loyalty
* shame
* persuasion
* diplomacy
* ideological drift
* leader personality
* NPC testimony

## Civic Layer — Legitimacy and Institutional Change

The civic layer handles authority.

It asks:

```text
What are we allowed to become?
```

It controls:

* votes
* courts
* budgets
* charters
* emergency powers
* land claims
* rights
* faction recognition
* treaties
* public works
* fork rights

## Chronicle Layer — Historical Identity

The Chronicle layer handles memory.

It asks:

```text
What story will survive?
```

It controls:

* era naming
* event records
* public histories
* memorials
* myths
* faction origin stories
* archive disputes
* propaganda
* historical evidence
* worldline identity

## Legitimacy Debt

When a faction violates its own sacred values to survive, it gains legitimacy debt.

Example:

A Mutualist Assembly uses forced labor to repair the waterworks.

The settlement survives, but legitimacy debt rises.

Effects:

* public trust decays
* NPCs remember hypocrisy
* opposition movements form
* future votes become harder
* Archive Orders may record the violation
* propaganda attempts increase
* schism risk rises

Legitimacy debt can be repaid through:

* public apology
* reparations
* trials
* truth commissions
* restored rights
* giving up emergency powers
* memorials
* successful public works
* leadership change
* constitutional reform

This turns ethics into long-term infrastructure.

## Archetype Coherence

Each faction should track coherence.

Coherence measures whether a faction’s actions match its stated values.

High coherence creates:

* NPC loyalty
* stable identity
* clearer diplomacy
* better morale
* stronger legitimacy
* more predictable laws

Low coherence creates:

* accusations of hypocrisy
* corruption
* faction splits
* coups
* cult behavior
* defections
* worldline forks

Coherence prevents procedural factions from becoming random mixtures.

## Schisms Instead of Forced Outcomes

A faction should not always transform as a whole.

High archetype tension can produce several outcomes.

## Reform

The faction changes policy but keeps identity.

Example:

A Mutualist Assembly creates a temporary defense council.

## Transformation

The faction slowly becomes a new archetype.

Example:

The defense council becomes permanent and dominant.

## Schism

The faction splits into two societies.

Example:

Some citizens preserve the commons while others found a Protectorate militia.

## Coup

A subgroup seizes control.

Example:

Security forces take food, roads, and gates under emergency authority.

## Exodus

A group leaves.

Example:

Anti-militarist citizens form a Refugee Ark or new Mutualist outpost.

## Fork

The worldline splits.

Example:

One branch chooses security rule. Another preserves the original commons.

This is where decentralization becomes gameplay.

## Seedworks Implementation Scope

The first vertical slice should not implement all archetypes fully.

Seedworks should prove the evolution architecture with four operational archetypes.

## 1. Mutualist Assembly

What players are trying to build.

Core question:

```text
Can trust survive scarcity?
```

## 2. Industrial Compact

The temptation of output at any cost.

Core question:

```text
Can production serve life instead of consuming it?
```

## 3. Null Ecology

Optimization without wisdom.

Core question:

```text
What happens when systems run after meaning dies?
```

## 4. Ghost Civilization

The warning from the past.

Core question:

```text
What did the old world fail to understand?
```

## Initial Evolution Paths

The Seedworks prototype should support a few clear evolution paths.

### Mutualist Assembly can drift toward:

* Security Protectorate after repeated raids
* Industrial Compact after scarcity/output pressure
* Archive Order after ghost discoveries
* Refugee Ark after disaster
* Machine Stewardship after robot-rights crisis

### Industrial Compact can drift toward:

* Debt Empire if tools and credit are monopolized
* Reactor Order if energy becomes central
* Security Protectorate if sabotage rises
* Null Ecology if automation escapes civic control

### Null Ecology can mutate into:

* Factory Bloom
* Signal Rot Swarm
* Defense Grid Remnant
* Logistics Parasite

### Ghost Civilization can resolve into:

* Archive ally
* Quarantine threat
* Null infection source
* Confluence warning
* recoverable lost settlement

## Final Principle

Faction evolution should make societies feel alive.

A faction should not simply exist.

It should become.

And when it becomes something new, the world should remember why.
