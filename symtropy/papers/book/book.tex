\chapter*{Reproduction}
\addcontentsline{toc}{chapter}{Reproduction}

All experiments reported in this book can be reproduced from the open-source repository:

\begin{verbatim}
cargo run --example [experiment_name] --release
\end{verbatim}

Seeds are deterministic. Results are bitwise reproducible on the same platform. Statistical methods, effect sizes, and Holm--Bonferroni corrections are computed inline and reported in stderr output.

55 experiment files. 45 findings. 95 library tests + 2 integration tests. AGPL-3.0.
