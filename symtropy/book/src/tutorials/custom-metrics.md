# Custom coupling metrics

> **Status:** stub — see [Generic state coupling](../core-concepts/generic-state-coupling.md) for a working worked example. A fuller gallery of patterns lands in Phase 2.

Planned coverage:

- **Health** — HP-gated motor authority (low HP → Orange tier).
- **Trust** — friction reduction in shared zones (resonance cooperation).
- **Skill** — tight motor precision bypass of prediction-error habituation.
- **Wealth** — inverse friction (easier sliding, richer bodies).
- **Reputation** — collision impulse dampening for trusted peers.
- **Mood** — time-integrated metric with exponential decay.
- **Fuel / Mana** — metric that also gates energy budget.

Each pattern will include a runnable example and a correctness test.
